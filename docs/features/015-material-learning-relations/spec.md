# 015 资料与学习记录关联

## 背景与目标

产品以资料为主干，围绕资料形成与 AI 的对话、笔记等内容。资料阅读、AI 管理和数据管理共同支撑本特性：从资料找到相关记录，从笔记返回原文，并在改名、分类调整或删除后保留来源。

## 功能与规则

- 官方学习资料、单道题目和用户上传资料复用现有编号。资料名称、学科、页码和版本不作为资料身份；具体引用仍保存其固定版本与位置。
- 阅读栏提供“相关内容”，查看这份资料各版本、各章节或页码下的对话与笔记。对话包括进行中和已归档记录，已删除记录不显示。同一对话多次引用同一资料只显示一次；普通对话实际引用了资料时也可从该资料找到。
- 打开进行中对话时沿用原会话和已有现场恢复流程；已归档对话打开历史内容并保持只读，不新建第三方会话。不同版本的对话分别保留，查看关联列表不改变会话绑定或版本。
- 在“相关内容”中点击“记录笔记”，填写标题、正文并选择笔记本。笔记记录打开编辑窗口时的资料版本及页码、章节或题号；保存后进入笔记页面。正文支持 Markdown，标题为 1–80 个字符，正文不能为空且最多 100000 个字符。
- 笔记页面支持编辑标题、正文和所属笔记本，保留资料来源与标签；“查看原文”打开保存时的固定位置。标签继续由 010 的学科目录及自定义标签管理，来源与标签用途分别明确，修改标签不改变来源。
- 删除资料或学科不连带删除笔记和对话。文件仍保留且可以读取时，历史来源仍可打开；来源缺失时显示不可用，笔记正文仍可阅读和编辑，不替换成其他资料。
- 新增笔记复用本机个人记录保存和修订号检查。保存失败、原笔记被删除或目标笔记本失效时保留输入；刷新不覆盖正在编辑的内容。未保存正文接入现有草稿备份和状态栏，应用更新前要求保存或取消。
- 兼容旧笔记的课程与题号关联，旧数据不批量重写；原有资料目录、文件和 Harness 会话规则保持有效。

## 验收

1. 从同一份资料的不同位置打开“相关内容”，能找到原对话和笔记；其他资料的记录不混入，重复引用不重复计数。
2. 在 PDF 的指定页、官方教材章节和题目中分别创建笔记，保存并重新打开后能回到原位置。
3. 编辑、转移或删除笔记后，笔记本与资料的相关内容同步；保存冲突不会覆盖其他窗口的新内容或重建已删除笔记。
4. 资料改名、移动学科、更新版本或删除后，原关联不丢失，历史版本不被当前版本替换。
5. 原有笔记、普通对话、归档规则、阅读现场及 AI 生成不受关联列表影响。日间与夜间使用同一主题变量。
