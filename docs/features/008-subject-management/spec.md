# 008 学科管理与上传确认

## 背景与范围

学生需要按自己的课程整理资料，并在上传前确定文件的所属学科和内容类型。学科分类独立于官方课程包，重命名不改变资料编号、课程编号或会话关联。

- “新增学科”位于学科列表底部。学科菜单支持新增，名称为 1–40 个字符，不允许与当前学科重名。“未分类”为固定分类。
- 在学科名称上右键显示“重命名”“删除”。删除前显示“高危操作，请谨慎确认”，并说明该学科及其已上传资料一并删除、文件和历史对话保留；需要保留资料时应先转移到其他学科；取消不修改任何数据。
- 删除分类后不再显示该学科，刷新或官方内容更新不会重新添加它。原官方课程包保留，历史对话仍可打开原内容。
- 点击“上传资料”先打开上传窗口，在窗口内选择或拖入文件，点击“下一步”后选择学科，默认使用上传入口所属学科；从未分类入口上传时默认未分类。可改选其他学科、未分类或新建学科。列表拖入的文件也进入同一窗口，不额外要求重新选择。
- 内容类型单选，默认“学习资料”；“题目”置灰，提示“不符合题目格式要求”。本次仍只上传 PDF/PPTX，不开放题目导入。
- 确认前不上传文件；成功后显示目标学科的资料列表。新建学科失败时保留输入；批量上传失败时保留失败文件和错误信息，允许修改后重试，已保存的文件不重复提交。

## 验收

1. 新增、重命名、删除在重新打开应用后保持一致；空名称、重名、保存冲突不显示成功。
2. 删除后，该学科的上传资料条目从资料列表移除，不进入未分类；已提前转移的资料保留。原阅读位置、历史引用、文件和会话绑定不改变。
3. 文件选择与拖入均经过相同的两步确认；返回上一步、取消和重试不提前上传。
4. 选择其他或新建学科后，上传记录使用对应稳定编号。重复上传仍按学科和文件内容判断。
5. 题目无法选中，损坏文件、超限、不支持的格式和服务不可用均有明确提示。
6. 新建学科保存后立即上传、批量部分失败后重试、资料查询响应倒序和读取缓存期间发生写入，均不能造成目录丢失、重复创建或旧资料覆盖新记录。
