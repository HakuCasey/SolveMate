# 018 本地数据备份与恢复

## 目标

用户能够保存完整的本地数据备份，在误操作、换电脑或更换数据目录时恢复资料及学习记录。入口为“设置 → 备份与恢复”。

## 范围

- 导出 ZIP：个人记录、学习时长、机器人与 AI 配置、原生会话关联、用户资料原件及派生文件、已下载内容和历史版本。
- 文件默认保存到系统下载目录，支持浏览器允许的其他保存位置；不覆盖同名文件。
- 恢复前检查格式、文件完整性、路径及数据库；确认后替换当前数据，先自动备份当前数据。失败恢复原数据，进程中断后启动时完成回退。
- AI 生成、连接检测、资料处理和其他数据操作进行期间不执行替换。恢复后统一刷新数据，未保存输入和草稿继续保留。
- 保留资料、笔记、对话和原生会话的稳定编号。第三方 Harness 的登录信息与原生会话文件不在本应用的数据目录中，不包含在备份里；继续对话仍由适配器查找原生编号。
- 不改变默认 `user/` 目录，不改变 Git 管理约定；发布前的默认数据位置与目录选择继续讨论。

## 验收

1. 导出后修改资料和记录，再恢复，原件、历史引用、笔记、机器人、会话编号与学习时长一致。
2. 无效文件、较新格式、损坏文件、越界路径、磁盘写入失败和中断恢复不损坏当前数据。
3. 恢复期间拒绝并发写入；旧窗口的旧版本保存不能覆盖恢复结果，刷新后读取新记录。
4. 备份不包含已有备份、临时文件、项目代码或外部 Harness 的凭据。
5. macOS 与 Windows 使用相同的数据格式，路径与文件保存由已有系统适配代码处理。
