# 018 本地数据备份与恢复

## 目标

用户能够保存完整的本地数据备份，在误操作、换电脑或更换数据目录时恢复资料及学习记录。入口为“系统设置 → 备份与恢复”。出现未解决的操作失败时，系统设置 Logo 高亮，菜单项显示红点。打开窗口即可查看操作、对象和失败原因。选择 ZIP 文件后显示文件名、备份时间和大小，确认后开始恢复。自动转换产生的 JSON 备份不属于该窗口的导入格式。

## 范围

- 导出 ZIP：个人记录、学习时长、机器人与 AI 配置、原生会话关联、导入资料的原件及派生文件、已下载内容和历史版本。
- 文件默认保存到系统下载目录，支持浏览器允许的其他保存位置；不覆盖同名文件。
- 恢复前检查格式、文件完整性、路径及数据库；确认后替换当前数据，先自动备份当前数据。失败恢复原数据，进程中断后启动时完成回退。
- AI 生成、连接检测、资料处理和其他数据操作进行期间不执行替换。恢复后统一刷新数据，未保存输入和草稿继续保留。
- 保留资料、笔记、对话和原生会话的稳定编号。第三方 Harness 的登录信息与原生会话文件不在本应用的数据目录中，不包含在备份里；继续对话仍由适配器查找原生编号。
- “加载用户数据”读取本机最新记录，使用与窗口重新获得焦点时相同的读取流程。

## 验收

1. 导出后修改资料和记录，再恢复，原件、历史引用、笔记、机器人、会话编号与学习时长一致。
2. 无效文件、较新格式、损坏文件、越界路径、磁盘写入失败和中断恢复不损坏当前数据。
3. 恢复期间拒绝并发写入；旧窗口的旧版本保存不能覆盖恢复结果，刷新后读取新记录。
4. 备份不包含已有备份、临时文件、项目代码或外部 Harness 的凭据。
5. 编辑数据路径时，取消会返回“备份与恢复”并保留原设置。保存后，在同一窗口可见待切换目录并撤销。
6. 切换到空目录时，勾选复制会带入现有记录、资料和备份；未勾选时首次打开只提供预置内容。
7. macOS 与 Windows 使用相同的数据格式，路径与文件保存由已有系统适配代码处理。

## 用户数据路径

桌面版和源码版均在“系统设置 → 备份与恢复”显示当前目录。点击“更改路径”进入编辑窗口，取消后返回“备份与恢复”。保存路径时可选择把现有数据复制到空目录，或直接使用目标目录中的记录；原目录保留。桌面版退出并重新打开后切换，源码版重启本机服务后刷新页面。切换前可撤销；复制或校验失败时继续使用原目录。
