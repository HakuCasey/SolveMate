# 010 技术设计

## 数据归属

`AppData.noteLibrary` 保存笔记本、笔记和自定义标签，沿用浏览器的个人记录数据库与事务保存，不新增本机服务接口。共享类型位于 `packages/contracts/src/index.ts`，校验及变更规则集中在 `state/notes.ts`，页面通过已有 `saveChanges` 提交。

| 对象 | 关键字段与关联 |
| --- | --- |
| `Notebook` | `id`、`title`、`revision`；固定编号 `notebook-unclassified` 表示“未分类” |
| `Note` | `id`、`notebookId`、`title`、`content`、`tagIds`、`revision`；保留现有 `courseId`、`questionId` 和旧 `summary`，列表不使用旧摘要 |
| `NoteTag` | 自定义标签的 `id` 与 `title`，统一保存于 `customTags`，笔记通过编号引用 |
| 学科标签 | 编号为 `subject:<学科编号>`，名称实时来自同一学科目录；不重复存储学科名称。固定“未分类”标签为 `subject:unclassified` |

学科标签与自定义标签各自保留身份。删除学科后，已有标签通过保留的学科记录显示原名称，新选择只列出有效学科和该笔记已应用的标签。创建同名标签复用当前已有项，不复制定义。

## 保存与兼容

旧记录缺少 `noteLibrary` 时，由初始化函数复制示例和固定笔记本并保存。已经存在的空笔记集合必须保留，不能按“空”重新初始化。新字段不改变 AI 元数据格式或原有对话。

删除笔记本时，在同一个 `AppData` 变更中移除笔记本，并按选择删除笔记或修改其 `notebookId`。修改关系时递增笔记修订号；笔记的编号、正文、标签和来源不改变。单条笔记删除不会删除其他笔记或公共标签。

窗口打开时保存目标编号及修订号。提交使用当前完整状态，核对目标仍存在且修订号一致，再通过 IndexedDB 的现有整体版本检查保存。保存成功才更新页面和提示；失败保留原状态和窗口输入。

## 界面

`NotebookList` 展示目录和两行条目，`NoteManagementDialog` 处理输入、标签选择及确认，不直接写存储。菜单、条目和纸页通过同一标签解析函数显示名称。预览由正文首行去除简单 Markdown 标记后截取，不调用 AI。

当前笔记转移后展开“未分类”；删除当前笔记后选取仍存在的笔记，空集合显示空状态。右键菜单和窗口使用现有主题变量，不新增独立配色。
