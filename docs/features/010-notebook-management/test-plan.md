# 选段记录与笔记本导出验证

## 改动点

1. 阅读栏与对话正文选段均提供添加到侧边对话、添加到笔记；对话选段排除名称和状态文字，保留原消息编号。四条引用限制、逐条移除与旧引用恢复规则继续有效。
2. 新建笔记、记录选段、更换笔记本共用同一目标选择；新建和保存一次提交，重名、目标删除、保存失败不改变原记录。选段保存后留在当前页面，笔记列表可看到新记录。
3. 编辑笔记保留选段快照；阅读来源返回固定位置，对话来源返回对应会话的原消息；原记录删除后仍保留选段文字。
4. 笔记本导出包含空笔记本、中文、代码、表格、行内与独立公式；检查分页、字号和内容是否完整。默认下载与选择位置分开，取消选择、取消导出、权限不足及不支持文件选择器分别处理。
5. 导出检查已保存的笔记编号与修订号；原记录变化时触发统一刷新。程序缺失、错误路径、超时、无效输出与客户端断开后均可重试，不删除笔记，只清理本次打印进程及临时目录。
