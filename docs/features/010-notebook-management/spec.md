# 010 笔记本与笔记管理

## 背景与范围

学生按笔记本整理学习笔记，需要修改名称、添加标签和删除条目。笔记属于数据管理模块，列表与纸页展示由资料阅读界面承载；正文创建、编辑及资料来源由 [015](../015-material-learning-relations/spec.md)扩展，沿用本特性的笔记本、标签和保存规则。

- 笔记本右键提供“重命名”“删除”。“未分类”为固定笔记本，不能改名或删除。
- 删除笔记本前显示“高危操作，请谨慎确认”，询问是否删除所有笔记。默认选“否，将笔记移入‘未分类’笔记本”；选择“是”则一并删除该笔记本中的笔记。两种选择均需点击确认，取消不修改数据。
- 笔记条目右键提供“重命名”“添加标签”“删除”，删除前再次确认。名称为 1–80 个字符；笔记本不允许重名。
- 条目显示两行：第一行标题，第二行标签与正文首个非空行的简短预览。长内容省略，不单独生成摘要。标签较多时显示前两个和剩余数量，悬停查看全部名称。
- 笔记列表与对话列表共用紧凑标题栏，图标、名称、数量在同一行，操作靠右。笔记右侧使用同样的标题栏，显示所属笔记本、资料来源入口和“编辑笔记”；正文独立滚动时标题栏保持可见。纸页保留笔记标题、自定义标签和正文，不显示学科标签或编辑按钮。未选择笔记时保留标题栏并显示空状态。
- 默认标签来自当前学科目录，示例笔记初始关联所属学科标签；用户可以多选、取消选择或新增标签。新增的自定义标签保存后，其他笔记可复用。同名标签创建时复用已有编号。
- 重命名学科后，已应用的学科标签同步显示新名称。删除学科不删除笔记或已应用标签；该标签不再推荐给其他笔记，已应用的标签仍可取消。
- 笔记本编号、笔记编号与标签编号分别稳定保存。笔记本删除和笔记转移／删除一次保存完成；保存冲突、失败时保留原数据并显示错误。
- 旧记录首次打开时初始化示例笔记和固定“未分类”笔记本，后续不再重建示例。删除当前笔记后显示其他可用笔记；全部删除后显示空状态。

## 验收

1. 重命名笔记本和笔记后，列表、正文及刷新后的内容一致。
2. 删除笔记本时，取消、保留笔记、删除全部三种行为分别正确；转移保留笔记编号、正文、来源与标签。
3. 学科新增、改名与删除符合标签规则；自定义标签创建与笔记引用一次保存，无重复创建或失效引用。
4. 删除单条笔记需确认，删除最后一篇后不报错，刷新不会重新出现。
5. 保存失败、旧修订号及其他页面的保存冲突不能覆盖新内容。
6. 两行条目、右键菜单和确认窗口适配日间、夜间及窄栏，笔记本展开／收起与纸页阅读保持可用。
