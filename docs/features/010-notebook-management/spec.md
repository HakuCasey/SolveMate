# 010 笔记本与笔记管理

## 背景与范围

学生按笔记本整理学习笔记，需要修改名称、添加标签和删除条目。笔记属于数据管理模块，列表与纸页展示由资料阅读界面承载；正文创建、编辑及资料来源由 [015](../015-material-learning-relations/spec.md)扩展，沿用本特性的笔记本、标签和保存规则。

- 笔记本右键提供“重命名”“删除”。“未分类”为固定笔记本，不能改名或删除。
- 删除笔记本前显示“高危操作，请谨慎确认”，询问是否删除所有笔记。默认选“否，将笔记移入‘未分类’笔记本”；选择“是”则一并删除该笔记本中的笔记。两种选择均需点击确认，取消不修改数据。
- 笔记条目右键提供“重命名”“更换笔记本”“添加标签”“删除”，删除前再次确认。笔记标题最多 24 个字，超出直接截断；笔记本名称为 1–80 个字符，不允许重名。
- 条目显示两行：第一行标题，第二行自定义标签与正文首个非空行的简短预览。长内容省略，不单独生成摘要；学科标签不显示。标签较多时显示前两个和剩余数量，悬停查看全部名称。
- 笔记列表与对话列表共用紧凑标题栏，图标、名称、数量在同一行，操作靠右。笔记右侧使用同样的标题栏，显示所属笔记本和“编辑笔记”；正文独立滚动时标题栏保持可见。纸页保留笔记标题、自定义标签和正文，不显示学科标签或编辑按钮。未选择笔记时保留标题栏并显示空状态。每篇笔记条目在标题后提供“查看来源（数量）”，点击展开该篇笔记的来源列表，单条与多条使用相同入口；零来源不显示入口。
- 默认标签来自当前学科目录，示例笔记初始关联所属学科标签；用户可以多选、取消选择或新增标签。新增的自定义标签保存后，其他笔记可复用。同名标签创建时复用已有编号。
- 重命名学科后，已应用的学科标签同步显示新名称。删除学科不删除笔记或已应用标签；该标签不再推荐给其他笔记，已应用的标签仍可取消。
- “更换笔记本”可以选择已有笔记本或新建笔记本。新建与转移一次保存完成；成功后列表立即显示目标笔记本，展开并选中已转移的笔记，正文顶部同步所属笔记本。笔记编号、正文、标签和资料来源保持不变；取消或保存失败不创建空笔记本，也不改变原归属。
- 展开笔记本后可点击“多选”，仅选择该笔记本中的条目；至少选中两篇才能合并。确认窗口按列表从上到下显示合并顺序，点击“确认合并”后形成一篇笔记，并自动打开。取消不修改笔记。
- 合并保留第一篇的标题、编号与列表位置，各篇标题与正文依次拼接，标签去重，资料位置与对话选段来源全部保留。合并后的来源从该篇笔记条目标题后的入口逐项查看；各原资料的“相关内容”均指向合并后的笔记。后续仍可编辑、更名、移动和导出。
- 合并一次保存全部变化。所选笔记已修改、删除或移入其他笔记本，以及合并正文超过 100000 字符时，不删除原笔记，显示具体原因；保存失败保留选择并可重试。
- 编辑笔记只显示标题和正文，不显示资料来源或笔记本选择；保存内容不修改笔记本归属。
- 笔记保存编号、所属笔记本、标题、Markdown 正文、标签、修订号、创建时间、更新时间和来源集合，不单独保存学科编号或正文预览。资料来源固定到版本及页码或题号，对话来源固定到对话和消息；来源只保存编号与定位信息，不保存引用原文或选段范围。
- 新建记录创建与更新时间，修改更新修订号和更新时间；已有笔记没有可靠时间时留空，不补造历史时间。现有记录先备份再转换，正文、标签、位置、对话与消息编号和列表顺序均保留，失败不覆盖原记录。
- 笔记本编号、笔记编号与标签编号分别稳定保存。笔记本删除和笔记转移／删除一次保存完成；保存冲突、失败时保留原数据并显示错误。
- 旧记录首次打开时初始化示例笔记和固定“未分类”笔记本，后续不再重建示例。删除当前笔记后显示其他可用笔记；全部删除后显示空状态。

## 验收

1. 重命名笔记本和笔记后，列表、正文及刷新后的内容一致。
2. 删除笔记本时，取消、保留笔记、删除全部三种行为分别正确；转移保留笔记编号、正文、来源与标签。
3. 学科新增、改名与删除符合标签规则；自定义标签创建与笔记引用一次保存，无重复创建或失效引用。
4. 删除单条笔记需确认，删除最后一篇后不报错，刷新不会重新出现。
5. 保存失败、旧修订号及其他页面的保存冲突不能覆盖新内容。
6. 两行条目、右键菜单和确认窗口适配日间、夜间及窄栏，笔记本展开／收起与纸页阅读保持可用。

7. 多选顺序不改变合并顺序；确认、取消、重复合并、跨来源关联及保存后重新打开符合合并规则。

## 选段与导出

- 阅读栏的学习资料、题目，以及对话栏中发送和收到的正文，选中文字后均提供“添加到侧边对话”和“添加到笔记”。待发送引用仍可逐条查看、移除，最多四条。
- 添加到笔记时显示已选内容和笔记本选择，可选择已有笔记本或新建笔记本。确认后保存为一篇笔记，选段成为笔记正文，来源仅保存编号与位置；取消不创建记录，失败保留输入并可重试。新建笔记、更换笔记本复用相同的笔记本选择组件。
- 笔记本右键提供“导出 PDF”，包括固定的“未分类”笔记本。导出包含该笔记本的全部笔记，空笔记本仅导出标题与空内容说明。
- 默认下载 PDF，也可选择保存位置；路径选择取决于浏览器支持，不支持时说明如何通过下载设置选择位置。导出失败可以重试，不改变笔记数据。
