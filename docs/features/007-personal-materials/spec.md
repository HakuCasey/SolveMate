# 007 用户资料导入与阅读提问

## 背景与目标

学生导入自己正在使用的 C 语言课本或课堂课件，在原页面上阅读，围绕选中的内容提问，并在下次打开时继续原对话。交互参考 Readwise Reader 的选段提问和 Zotero 的原文定位；资料和引用沿用项目已有元数据设计。

涉及资料阅读、数据管理和 AI 管理模块，使用现有本机服务与 Harness 适配器。官方内容服务不接收用户文件。

## 首版范围

- 支持有文字层的 PDF 和 PPTX；单文件上限 100 MiB。PPTX 通过本机 LibreOffice 转换为 PDF，保留原件。旧版 `.ppt`、扫描件 OCR、图片附件、多资料检索后续安排。
- 科目下的“学习资料”列表提供文件选择与拖入，按 [008 学科管理与上传确认](../008-subject-management/spec.md) 选择学科与类型后开始上传，默认使用当前入口所属学科。导入后先保存原件，再处理；失败保留原件、错误和重试入口。
- 使用 PDF.js 显示原页面，支持页码跳转、翻页、缩放和文字选择。选中文字后，在选区上方弹出“添加到侧边对话”，确认后加入待发送引用；点击空白处取消临时选区。每次提问最多添加 4 条内容，超出时提示“为保证对话质量，当前最多支持 4 条内容。”；移除一条后可继续添加。各条紧贴输入框上沿显示前 15 个字、全文展开入口和删除按钮，不显示资料标题等额外说明。
- 没有可提取文字的页面仍可阅读，但不把空内容当作已交给 AI；明确提示当前不支持该页的图片理解。
- 保存资料编号、固定版本、原件及阅读文件；引用保存页码与文字快照。重命名文件、翻页或后续提问不改变历史引用。
- 同一份资料不同页可以继续同一对话。返回对话时恢复原资料，在本次打开期间优先恢复该资料最后阅读的页码，并展开左侧对应学科；点击历史引用返回对应页。
- PDF 缩放按资料和版本保留，页内双向滚动按页码保留，待发送引用在同一资料各页间共用；切换页面或其他资料再返回不重置。渲染完成后恢复位置，页面加载不覆盖已有记录。
- 原件和派生文件保存于 `user/uploads/`；浏览器缓存已经打开的阅读文件，用于本机服务暂不可用时阅读。缓存失败单独说明，不否认本机已保存的原件。
- 继续兼容现有教材、题目、普通对话和旧记录；切页或切换页面不停止正在生成的回复。

## 验收

1. 工作区提供的两份 PDF 与一份 PPTX 均可导入、显示与重新打开；课件转换后核对页数和代表页面。
2. 选中课本代码提问，核对实际 Harness 请求中的文字、资料名和页码，完成真实回复与追问；不调用 Codex 测试。
3. 页面切换、刷新、返回对话后资料与原生会话关联保持一致；引用可以返回原页。
4. 覆盖损坏文件、超限文件、转换器缺失、转换失败、服务重启与重复导入；失败不覆盖已保存文件。
5. 自动检查 macOS、Windows 转换程序查找与进程参数；Windows 真机效果待有环境时验证。

## 按科目组织资料与题目

- 每个科目下提供“学习资料”和“题目”两个入口，个人上传文件在所属科目的学习资料列表中管理。
- 点击入口先在中间栏显示列表，学习资料列表同时包含该科目的内置内容和用户文件。点击条目后打开阅读，阅读栏左上角提供返回对应列表的按钮，不增加侧栏中的文件层级。
- 学习资料列表提供文件选择与拖入；选择文件后，点击“下一步”确认学科和内容类型，再开始上传。学科默认使用当前入口，可以改选、新建或选未分类；保存后显示目标学科的列表，处理状态和失败重试在条目中显示。
- 题目先显示题目列表，打开后保留参考答案开关和上一题、下一题。本次不开放新增题目；后续准入要求题目与答案分别上传并进行校验。
- 已有未分类或原科目不在当前目录的用户文件保留在“未分类 → 学习资料”中，可以调整所属科目。变更归属不改变资料编号、文件版本或历史引用。
- 上传资料的条目支持右键“重命名”“移动”“删除”。重命名修改显示名称，移动选择其他学科或未分类；删除前确认“该资料将从列表中删除，文件和历史对话保留。”。内置课程内容沿用官方内容包管理。
- 三项操作使用同一资料编号和修订号，保存冲突时读取最新记录并提示重试。处理结果不能覆盖改名、归属或删除标记；旧记录缺少删除标记时继续正常显示。已删除条目不出现在任何学科，历史对话仍能读取原文件、页码和引用。
- 同一科目重复导入同一文件复用记录；不同科目分别导入同一文件时不移动另一科目的资料。
- 返回列表或切换科目不取消正在生成的回复。对话列表的“返回对话”和历史引用仍能直接恢复对应资料、页码或题目。
