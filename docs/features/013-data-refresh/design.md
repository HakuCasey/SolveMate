# 013 数据刷新与冲突处理设计

## 职责

`refresh/coordinator.ts` 集中登记记录、资料、课程和 AI 连接的读取函数，合并并发读取，并统一处理窗口重新获得焦点、恢复可见、恢复网络和手动刷新。应用更新后的页面通过 `pwa/reload-refresh.ts` 调用同一协调器；个人记录首次读取暂时失败时自动再读一次，仍失败才交给手动“重新读取”。普通刷新和没有更新应用时的数据异常不增加这次自动重试。同一秒内的窗口事件合并，不周期读取全部业务记录。写入使旧查询失效时，最多补读一次；读取失败不递归刷新。业务写入不由调度器重放。资料转换进度和 AI 流式回复仍使用原有任务编号及进度读取。

HTTP 错误统一包含 `code` 和 `status`。404、409 触发相关记录刷新；字段校验、服务中断与格式错误分别说明，不按报错文字猜测冲突类型。

## 已确认记录与本页修改

`LocalDataController` 分别维护上次确认的记录、本页工作副本与刚读取的正式记录，按稳定编号进行三方比较：

- 一方未改变的字段采用另一方值；不同对象或不同字段的修改合并。
- 同一字段两方都有不同修改时保留本页内容，记录字段位置与双方值，等待用户选择。后续刷新更新比较值，不能把尚未选择的冲突视为已确认。
- AI 配置、原生绑定及执行快照作为整体比较，不能混合连接与模型、原生编号等关联字段。AI 回复按执行编号和结果修订号采用匹配的结果与正文。
- 已删除的会话以正式删除状态为准。物理删除的其他对象若含本页修改，则保留备份并要求移除失效对象，不自动重建。

刷新与配置提交串行，期间到达的回复暂存，读取结束后处理；不关闭流式连接。窗口的阅读入口保留在本窗口。合并后有未确认修改时不自动写回，避免重做删除或覆盖已变更的内容。

## 表单输入与保存失败

`refresh/drafts.ts` 的 `UnsavedFormStore` 只登记当前窗口是否有未提交的表单，用于更新应用前的检查，不复制输入内容，也不写入浏览器缓存。输入由编辑组件维护；取消、保存或卸载时撤销登记。启动时只清理旧 `form-draft:` 缓存，不清理正式记录、尚未发送的提问或失败事务备份。

存储控制器单独保留已提交但保存失败的候选记录及原基线。当前失败操作通过 `failedCommits` 对应到备份；“重试”先读取最新记录，按基线合并，存在冲突时交由用户选择。成功后清除对应的当前失败与已恢复副本。此备份用于防止失败提交丢失，不作为历史表单列表展示。尚未发送的提问继续按对话或阅读范围编号保存。

`RefreshControls` 从统一操作状态取得失败信息，并显示记录读取、重试和冲突处理入口。操作详情始终可打开，只展示当前未解决的失败；同一操作重试成功后移除。最近 50 次失败保存在诊断日志中，通过独立按钮导出，不恢复为当前失败。未提交的表单不产生操作结果或诊断记录。状态与诊断的职责见 [014](../014-status-bar/design.md)。

需要修订号的编辑使用共用检查。读到更新后的记录不会重置仍打开的表单，保存时核对版本；原对象已删除时拒绝以旧修改重新创建。

## 文件变化

资料服务在列表和单条读取时计算 `availability`，不修改资料编号、版本或正式修订号。原件与阅读文件分别判断；记录损坏以 422 返回，缺失以 404 返回。部分列表无法读取时保留已有缓存条目并标记不可用，不能把损坏误认为删除。

课程索引返回版本文件是否存在。缺失时继续保留正式索引；有校验通过的缓存时仍可阅读，并提示恢复或重新下载。单份课程无法读取不阻止其他课程、笔记和对话打开。缓存只能在服务不可达或服务故障时作为读取副本，不掩盖位置不符或格式错误。

## 验证

以下为 2026-11-12 的验证记录。测试覆盖并发读取合并、递归刷新防护、独立修改合并、同字段冲突与再次刷新、删除后的草稿、缓存慢写取消、保存失败副本、刷新期间回复接收及文件缺失恢复。251 项网页测试、19 项脚本测试、200 项本机服务测试与 24 项社区内容服务测试通过，另有 2 项按条件跳过。TypeScript、ESLint、Prettier、Ruff、依赖一致性、共享 Schema 检查及网页构建通过。

同次验证在 Chrome 使用独立本机目录和两个不同站点缓存，验证另一处保存后的表单保留与过期提示、断线期间的输入、同字段草稿冲突比较及选择、应用更新后的草稿恢复、资料文件删除与恢复、原笔记删除后的保存拦截，以及日间和夜间的提示窗口。后台执行与刷新交错通过自动测试验证，未调用真实 Codex 或其他模型。正式服务重启前确认没有运行中的 AI 请求或资料转换，重启后核对个人记录及原生 AI 数据库内容未变。

本次浏览器操作在 macOS Chrome 完成，Windows 真机和其他浏览器的实际操作尚未验收；自动检查不能替代这些环境的实际操作。
