# 011 应用更新提示与重载保护

## 背景与目标

页面使用本地缓存打开，更新检测和下载在后台进行。用户需要随时知道是否发现新版、是否已准备完成，也需要主动检查和明确的失败反馈。

## 行为与验收

- 正式网页的右下角保留“检查更新”入口。打开页面时检查，恢复网络时重查；返回页面时至少间隔一分钟再查，持续打开时每小时检查一次。
- 按实际结果显示“正在检查更新…”“已是最新版本”“正在下载更新…”“新版已就绪”。没有新版时三秒后恢复检查入口；检测和下载过程中不重复发起操作。
- 只有服务端检查成功且没有新版本等待或下载时，才显示已是最新版本。离线、服务不可达、错误响应、下载失败或超时分别显示错误，允许重试，保留已有离线版本。
- 新版准备好后轻提示一次，右下角保留“更新应用”。用户点击后启用新版；其他窗口启用新版时，本页仅提示，不自动重载。
- 重新加载前保存当前窗口的输入草稿、已添加引用、阅读滚动、PDF 缩放、答案展开和最后阅读位置。更新后仍进入对话页；打开原资料或返回对话时恢复这些记录。
- 本地记录正在保存、保存失败，或机器人配置尚未保存时，明确提示并保留当前页面。临时状态写入失败时停止重载，不丢弃草稿。
- 更新不主动停止 AI 执行。已保存的运行编号由现有恢复流程重新订阅，本机服务继续处理原请求。
- “安装应用”仍由浏览器提供，不与检查更新或课程内容更新混用。普通刷新或关闭后的全面现场持久化不在本特性范围内。
