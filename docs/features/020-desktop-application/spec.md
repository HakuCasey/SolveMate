# 020 桌面安装版

## 背景与目标

源码启动方式要求用户准备 Node.js、Python 和项目依赖，不适合作为正式产品的主要使用方式。桌面安装版应将现有网页、本机服务及其运行环境放入同一个安装包，用户完成安装后可以直接启动应用。

本特性不另建一套资料、对话、笔记、机器人或教研室界面。桌面版复用现有 React 页面、本机接口和数据结构，只负责应用窗口、本机服务生命周期、系统数据目录和安装包。

## 使用过程

1. 用户下载与自己操作系统和处理器匹配的安装包并完成安装。
2. 用户从系统应用列表启动 SolveMate，应用自动启动本机服务并打开现有界面。
3. 全新数据目录提供高等数学与 C 语言的教材、题目及三个教研工具，对话与笔记均为空。用户可打开预置资料或导入自己的 PDF，并按需连接已安装的 Harness。
4. macOS 和 Windows 首次以 1280 × 760 的窗口居中打开，再次启动时恢复上次调整的普通窗口大小。屏幕放不下时按可用空间缩小。macOS 上点红色关闭按钮会隐藏窗口，点程序坞图标即可回到原页面；Windows 上点关闭按钮会退出应用。
5. 退出应用（macOS 上按 ⌘Q）时，本机服务随应用退出；再次启动后继续读取原有资料和记录。

## 当前范围

- macOS 使用 DMG，Windows 使用带安装向导的 Setup.exe。
- 安装包包含 Electron、网页文件、Python 运行环境、本机服务依赖和基础示例内容，不要求用户另装 Node.js 或 Python。
- 个人数据默认写入系统应用数据目录，可在“系统设置 → 备份与恢复 → 用户数据”更改，内部继续使用 `app.sqlite3`、`uploads/`、`community/`、`backups/` 和 `ai/`。
- 桌面程序以单实例运行，固定使用回环地址 `127.0.0.1:43127`。端口被占用时提示用户关闭占用程序后重试，不连接来源不明的已有服务。
- 窗口先显示启动页。本机服务就绪后进入对话页面，服务异常退出时可重启服务或退出应用。
- 桌面版不注册 PWA Service Worker。网页和桌面版继续共用页面与接口；应用更新的下载和安装后续接入桌面发布服务。
- 社区内容服务仍独立部署，不随客户端安装。未配置正式服务地址的内部安装包可以使用随应用提供的基础内容，但不能检查社区新版。

## 外部软件

- PDF 导入和本地记录不需要额外软件。
- AI 回复需要用户安装并配置至少一个受支持的 Harness。
- PPTX 转换继续使用 LibreOffice；未安装时保留原文件并提示安装 LibreOffice 或改用 PDF。

## 不在当前范围

- 不把社区内容服务或 LibreOffice 装入客户端。
- 不自动扫描和搬移用户电脑中的源码目录；源码版用户通过现有 ZIP 备份与恢复转移资料和记录。
- 正式分发签名、macOS 公证和桌面应用自动更新列入发布待办。
- 不承诺未经实机验证的 Windows Harness 调用。

## 验收标准

- 在未安装 Node.js 和 Python 的干净系统中，安装包可以完成安装并启动应用。
- 启动后能够导入和阅读 PDF，资料与记录保存在系统数据目录；关闭并重开后仍可读取。
- 关闭应用后不保留其本机服务进程；重复启动只保留一个应用实例。
- 本机服务启动失败、端口被占用或运行中退出时显示具体结果，不把失败显示为可用。
- Web/PWA 的现有启动方式和页面行为保持可用。
- macOS Apple Silicon 和 Windows x64 分别完成安装、启动、重开和卸载验收；Windows 自动构建不能代替实机验收。
