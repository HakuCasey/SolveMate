# Hermes 推理等级验证

## 测试范围

- ACP 提供 `reasoning_effort` 时，读取原生选项并设置等级，核对返回值；不再调用兼容入口。
- 旧版使用原生 Gateway SDK，读取安装提供的等级；仅修改指定会话，回读值必须与所选值一致。
- 恢复原生编号后再次应用所选等级；切换模型保留可用等级，原生返回新选项时及时更新。
- 不支持的等级、运行命令格式变化、超时、取消、设置后回读不一致均不能显示为成功。
- 读取补充配置失败时保留已经取得的原生编号；重试恢复该编号，不新建会话。
- macOS、Windows 路径按参数数组传递，保留 Hermes 官方生成的隔离 Python 启动环境；取消和超时只关闭 SolveMate 创建的子进程。

## 验证结果

2026-11-13，在 macOS 使用独立主目录和一个登记的 Hermes 原生会话完成验证：High 设置后回读一致，关闭 ACP 客户端后严格加载同一编号仍为 High，再改为 Medium 后回读一致。返回 8 个原生等级，原有全局模型、推理等级和供应商配置未改变。未请求模型生成回复，未调用 Codex。

自动测试覆盖原生 ACP、旧版兼容入口、恢复后重新应用、格式变化、超时、取消、回读不一致，以及补充配置读取失败后的同会话重试。Windows 已覆盖参数传递和共用进程清理；真实安装与账号调用仍需 Windows 实机验证。
