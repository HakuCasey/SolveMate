## 涉及的模块与功能

依据[模块架构](../../architecture/overview.md#模块架构)，本特性涉及：

- 资料阅读：PDF/PPTX 学习资料与题目阅读、阅读导航和阅读位置恢复。
- AI 管理：会话管理、机器人配置管理、提问内容组织及回复接收与请求控制。
- 数据管理：资料查询与读取、会话与消息存取、机器人配置存取、阅读记录存取，当前资料范围包括上传资料和社区资料。

阅读内容按资料或题目的稳定编号、固定版本和页码或题号恢复；应用保留各位置的滚动、答案展开和已添加引用。选中文字后点击“添加到侧边对话”，片段才进入输入框上沿的引用列表；每条显示前 15 个字，可展开全文或单独删除。未添加选段时，资料阅读会话仍按当前页或用户明确选择的页码提供参考范围。PDF、PPTX 的导入、页码与引用见 [007](../007-personal-materials/spec.md)。

桌面阅读页的资料栏与会话栏、对话页的列表与消息栏支持拖动分隔线调整宽度，双击恢复默认比例；两页共用本地保存的比例。两侧保留最小宽度，窄屏使用上下布局，返回桌面布局后恢复原比例。左侧菜单支持手动收起为图标栏。阅读页默认按约 62% 和 38% 分配资料栏和对话栏。

## 背景

用户阅读课程资料或题目时，可能对原文、相关概念、某一步变形或推导依据产生疑问。阅读助手在保留当前资料位置的前提下提供文字询问和连续追问。

用户已经在阅读题目，提问时不应被要求重新输入完整题干。系统需要知道当前题目，并结合当前对话解释相关内容。是否已经理解由用户自行判断，产品不设置答疑成功或问题解决状态。

## 目标

- 面向大学生，内置示例学科为高等数学和 C 语言。
- 用户能够选择并阅读系统内置题目。
- 用户能够从学科页面选择学习资料或题目，并打开具体条目阅读。
- 用户能够通过纯文字围绕当前题目询问概念、步骤和推导依据。
- 助手自动获得当前题目的上下文，并支持同一题目内连续追问。

## 非目标

- 自定义题目集导入；PDF/PPTX 学习资料导入由 007 提供。
- 拍照录题、OCR 或图片内容识别。
- “已经理解”“答疑成功”“问题已解决”等状态或完成按钮。
- 判断学生是否学会、自动评分或测评学习成效。
- 跨会话的个人长期记忆、薄弱知识诊断和社区插件平台。

## 内容范围

- 首批内置题目为 `data/calculus/questions/questions.json` 中的 24 道原创示例题，编号 M001–M024。
- 增加 C 语言示例学科：`data/c-language/questions/questions.json` 中的 12 道程序阅读题（C001–C012）、`textbooks/` 中的示例资料源文件，以及 `memory/` 中的 12 个记忆点和 6 组讨论点。示例程序采用 C11；本次扩充不包含在线编译或代码运行功能。
- 题目包含题干、参考答案和讲解要点；用户在中间题目栏选择是否显示答案，显示参考答案时一并展示讲解要点；答案默认隐藏，切换内容后重新隐藏。
- `data/calculus/textbooks/` 和 `data/c-language/textbooks/` 维护社区示例资料的发布源文件；应用统一使用其 PDF 阅读版本，不再提供 Markdown 章节阅读方式。
- `data/calculus/memory/` 为基于示例资料提炼的课程记忆点和讨论点。是否参与首版回答，以及如何参与，尚待确定；现有文件不表示个人记忆功能已经实现。

## 用户场景

- 用户阅读 M001，不理解为什么分子可以有理化，直接询问“这一步为什么要乘共轭式？”
- 用户阅读 M005，询问“为什么不能直接用幂函数的求导公式？”
- 助手解释某一步后，用户继续问“这里为什么能约掉 x？”，无需再次粘贴题目。
- 用户选择另一道内置题后，可以围绕新题目提问。

## 运行方式与本地数据

SolveMate 按长期发展的学习客户端设计，首版提供网页并支持安装为 PWA，后续考虑桌面客户端、手机 App 和小程序。学习内容、会话、笔记和机器人配置以终端本地保存为主；关闭页面或重新进入后，应能恢复已保存的数据。

“离线”指终端无法连接 SolveMate 社区服务，届时不能获取新的题库或知识库，已完整下载的内容和本地记录继续可用。应用本身及所需资源也要支持离线重新打开。AI 是否可用，取决于用户配置的 API 或本机 harness 是否可达，独立于社区内容服务的状态。

首版接入现成 Harness，不自研 Harness。当前通过本机服务接入 DeepSeek Harness、Hermes 与 Codex；三项服务分别由适配器处理程序启动、连接检测、模型选项和原生会话恢复，共用对话管理与显示规则。在线调用时，所需资料和会话上下文会发送给相应 AI 服务。整体技术方向见[整体架构](../../architecture/overview.md)。

## 页面布局

桌面端使用从左到右的三栏结构：

- 左侧为窄功能菜单栏，从上到下为“学科”“对话”“笔记”“教研室”“机器人”，底部是“系统设置”；主入口使用同宽、同高、对齐的圆角长条框。菜单入口负责切换整个工作区，用户头像、学习勋章和底部设置采用气泡交互。
- 点击“学科”后，中间区域顶部显示“资料选择”。左侧为学科列表，右侧在“学习资料”和“题目”之间切换并显示条目数量；选中的类型使用平面高亮，不使用凸起的滑块样式。打开学习资料后使用 PDF 阅读器，打开题目后显示题干、参考答案开关和上一题／下一题入口；返回按钮与当前资料或题目集标题位于同一标题栏。
- 右侧为聊天栏，顶部为机器人选择器，与“机器人”配置页的已保存机器人同步；下方横向排列对话页签，点击切换对话，再点选中的标题可打开管理菜单，与对话条目右键菜单共用重命名、标签、归档、移回进行中及删除操作。标题右侧的「＋」在当前页面新建对话，阅读资料和教研室的选择随新对话保留。原对话正在生成的回复继续归入原对话。下方展示对话和文字输入框，生成期间不能重复提交。归档对话隐藏提问和推荐区。

上述阅读布局对应“学科”页面。“对话”页面中间为会话条目列表，右侧为选中会话的完整聊天记录和输入区，可继续对话；“笔记”页面中间按笔记本展开笔记条目，右侧展示选中笔记正文；“机器人”页面展示机器人列表和所选机器人的配置面板。三个入口均切换为独立界面，不以气泡展示列表。

应用首次打开、刷新或更新应用后，统一进入“对话”页面，默认显示最近的未归档对话；没有进行中对话时显示空列表与默认提问界面，不自动新建会话。已保存的阅读内容继续保留，可从学科入口或“返回对话”打开。

头像右侧显示累计学习和连续学习各自已获得的最高勋章，近 12 周的学习足迹热图位于设置上方。点击勋章可查看今日、本周、连续天数、累计时长及点亮条件；热图颜色深浅表示每日学习时长。统计口径、暂停条件和勋章门槛见 [017](../017-study-time/spec.md)。

页面高度适配当前窗口。桌面端资料／题目正文和聊天记录分别纵向滚动，顶部标题栏、题目导航与聊天输入区保持可见，长内容不撑高整个页面。文字自动换行；过宽公式可在公式区域横向滚动，代码保留缩进并适配栏宽，内容不得覆盖相邻栏位。窄屏上下排列阅读与聊天区域。

阅读、对话和笔记页面均可拖动两栏间的分隔线调整宽度，共用本地保存的分栏比例。笔记左栏为列表、右栏为正文，分别保留最小宽度；支持双击恢复默认比例、左右方向键调整和刷新后恢复，窄屏上下排列时隐藏拖动入口。

聊天栏无历史消息时使用统一的普通对话引导，不根据正在阅读的资料或题目更换文案。教研室使用独立的任务引导，见 [019](../019-question-research/spec.md#页面文案)。

应用按专业侧重预置“全科教师”“高数教师”“C 语言教师”三个机器人，名称可自定义，专业侧重写在角色指令中，不单设简介和专业范围字段。专业侧重不限制提问或会话关联；用户可选择名为“英语教师”的机器人回答数学问题，系统不拦截，也不自动更换。每个机器人分别配置角色指令、模型、记忆与能力，后续的 Skill 与 RAG 库也应分别挂载。当前尚未实现 Skill 安装和 RAG 检索。

输入框内部底部同一行显示资料位置、语音提示和提问／停止按钮；资料位置在左，语音提示紧邻右侧按钮；长资料名和提示文字省略显示，悬停可查看全文，不另外占用输入框下方的空间。语音采集与识别尚未接入，保留“尚未开放”说明。

点击侧栏头像，菜单首项为“账号设置”，下方用横线分隔。点击该项打开账号设置对话框，可预览或恢复头像、编辑昵称与个性签名。三项一起保存或取消；昵称最长 14 个字，签名选填，最多 120 个字；昵称仅在账号设置中显示。头像与系统设置菜单共用单色图标和菜单行样式。头像右侧的爪印和菜单中的“虚拟宠物”打开同一宠物气泡。默认宠物可改名，未领养时爪印置灰，点击提示领养。显示宠物、投喂、玩耍和邀请好友暂未开放。菜单底部保留“退出登录”，上方用横线分隔；未登录时置灰。

用户可以自行输入问题。由 AI 生成推荐问题仍待后续设计。

## 功能要求

1. 提供内置题目的选择入口，并展示所选题目的完整题干。
2. 题干和助手回复中的数学公式应可阅读；纯文字交互允许用户输入包含数学表达式的文字。
3. 用户通过文字输入框提交询问，系统返回与当前题目及询问相关的讲解。
4. 从阅读页提交的询问自动关联当前题目，用户无需重复输入题干。
5. 同一题目的连续追问可利用当前对话的上下文；用户要求解释某一步时，应围绕该步骤说明。
6. 切换题目后，新的询问应以新选题目为当前题目，不混入其他题目的会话。已有会话保存在本地，可通过“对话”列表重新打开并继续；关闭页面或重新进入后恢复已保存记录。
7. 不要求用户标记理解或完成，用户可按自己的阅读节奏继续询问或离开。
8. 请求进行中和请求失败时应有可见状态，避免用户无法判断是否已经提交或收到回复。
9. 中间题目栏允许用户显示或隐藏参考答案，切换显示状态不改变当前题目。
10. 右侧聊天栏隐藏推荐问题入口。
11. 后续接入 AI 推荐后，点击推荐问题后，将其作为用户询问进入当前题目的对话；用户仍可自由输入其他问题。
12. 点击“学科”切换到统一选择页面；学科列表、“学习资料／题目”类型和条目列表在同一工作区中联动，其他页面不保留一套学科树状态。
13. 题目阅读支持上一题和下一题导航并同步聊天上下文；学习资料使用 PDF 阅读器，支持连续／单页显示、翻页、页码和缩放。
14. “对话”是会话管理页面入口，中间展示会话列表，顶部使用与笔记列表一致的紧凑标题栏，图标、名称与数量同排，右侧为“新建对话”；右栏展示选中会话记录并支持续聊。选择会话时恢复机器人及聊天记录；存在阅读关联时，再恢复对应学科和题目／章节；不同会话的消息分别保存。底部“系统设置”采用两级气泡交互，一级依次提供 AI 配置、显示设置、社区内容、备份与恢复、帮助与反馈。帮助提供使用指南，反馈打开项目的 GitHub Issues，备份恢复打开本机数据管理窗口。它们不作为主菜单中的树状子项展开，也不插入阅读页顶栏。
15. 点击头像打开菜单，点击外部或按 Escape 收起。
16. 聊天栏顶部的“Aa”调整对话消息与输入内容的字号，范围为 8–21px，默认 12px。题目、参考答案与笔记正文保留原有字号。PDF 保留原页面排版，通过阅读栏缩放调整大小。外观支持“白天模式”“夜间模式”，切换后整个产品界面的颜色同步变化，当前阅读内容和对话不变。
17. “笔记”入口位于“对话”下方，点击切换为笔记页面。中间按笔记本展开条目，条目显示标题、标签与正文首行预览；右侧将整篇笔记呈现为连续纸页，页内保留标题、自定义标签和正文，不重复显示学科标签。两栏顶部使用独立的紧凑标题栏，右侧标题栏展示所属笔记本、资料来源入口和“编辑笔记”，不将操作按钮放进纸页。纸页使用细纸纹、淡点阵、页边线和装订孔，配合小圆角、细边框、轻阴影及页边留白，外侧背景略深；夜间模式使用对应深色。纸纹随应用本地保存，来源与许可见第三方说明。纸页宽度随右栏调整，长内容自然延长并在右栏滚动，切换笔记从页首开始。正文沿用原有阅读字号，代码、公式和表格保留原有排版。笔记的创建、编辑与来源保存见 [015](../015-material-learning-relations/spec.md)。
18. “机器人”入口位于“教研室”下方，点击切换为独立配置页面，支持创建多个机器人并分别保存配置。默认提供“全科教师”“高数教师”“C 语言教师”。角色设定包含名称和角色指令，AI 选择包含服务、模型和推理等级，记忆与能力选项当前只保存配置。配置页的“使用此机器人”为其创建不关联资料或题目的普通对话；聊天栏顶部切换机器人时先确认，再开始新对话，原对话及其机器人关联保留。新建、改名并保存的机器人同步出现在选择器中。
19. 在机器人列表条目上点击鼠标右键，可选择“设为默认”“复制”“删除”。默认机器人用于“新建对话”，与当前会话的选择独立；设为默认不改变已有会话。复制生成名称可区分、配置可独立编辑的新机器人。删除后，已有消息及其原属机器人的名称和图标保留，后续回复改由有效机器人发送；若删除默认机器人，剩余的第一个机器人成为默认。允许删除全部机器人，此时显示新建入口，在创建机器人前不能发送消息或新建对话。
20. 社区内容服务不可达时，用户仍能重新打开应用，阅读已保存资料、题目和历史记录，并使用本地保存的配置。AI 连接可达时仍可询问；不可达时展示明确的连接状态。
21. 联网可检查并下载内容更新，下载失败保留原有可用内容；更新应用或内容时保留个人记录。本地数据的备份与跨平台迁移方案在存储设计中细化。

首次使用时，对话和笔记均为空。社区学习资料、题目和教研工具随应用提供。

### 普通对话与阅读关联

从机器人页面“使用此机器人”或对话列表“新建对话”开启的会话是普通对话，不绑定当前资料、页码、题目或学科。普通对话发送、切换或重新打开后均保持空关联。

从学科阅读页提问时，才将当前资料页码或题目关联到新会话。普通对话与上次阅读位置分别保存；切回阅读页不会把普通对话改成阅读关联对话，历史消息继续保留发送时的关联。

### 会话条目管理

一条对话对应一个 AI session，具有独立、稳定的本地编号。列表分为“进行中”和“已归档”两个长条分组，点击标题可展开或收起；进入页面时进行中默认展开，已归档默认收起。已归档标题默认位于列表可用区域中部；只有进行中的展开内容超过上半区域时才向下移动，收起后回到中部。条目过多时列表内部滚动，已归档标题仍在窗口内可见。进行中表示未归档，不表示 AI 正在执行。

每条对话标题后显示标签，默认“无标签”。右键菜单提供重命名、标签、归档和删除；标签气泡提供重要、一般、无标签、自定义标签，自定义名称最多 24 个字符，可复用已有名称。已归档条目可移回进行中。归档不改变消息，仍可打开查看；右侧隐藏输入框、推荐问题和重新提问入口，用户须右键选择“移回进行中”后才能继续提问；删除后从列表隐藏，并取消当前选中状态。本轮删除使用本地删除标记，不删除外部 harness 的 session；回收站和彻底清除另行设计。

对话条目保持两行：第一行为标题与标签，第二行为“学科 · 资料或题目 · 最后一次提问”。最后一次提问直接读取最近一条用户消息，不调用 AI 生成摘要，也不增加持久化字段；长文字单行省略，悬停可查看完整信息。普通对话显示“普通对话 · 最后一次提问”，尚无提问时显示“还没有提问”。

每个进行中的条目均提供“返回对话”，不以 AI 是否仍在生成为条件。有关联资料时，按原会话编号恢复学科、资料版本、页码或题目、机器人、AI 配置和消息，并进入同一个阅读页面；普通对话仍在对话页面定位。点击条目本身继续在对话页面查看记录。已归档和已删除的对话不参与自动恢复。

从学科页面选择资料或题目时，同学科、同类型保留当前选择；切换学科或类型后展示对应列表，不自动打开第一项。打开具体资料或题目后，优先恢复当前版本最近的未归档对话；没有对话时显示默认等待提问界面。从条目显式返回某个旧对话时保留用户点选的编号。

切换页面或阅读内容不停止正在生成的回复，后台结果仍按原会话和执行编号保存；返回时显示已收到的正文与最新状态，不创建替代会话、不重复提交问题。原有会话记录保存内容关联，应用层统一保存本次打开期间的阅读状态，包含每份资料最后的章节或页码、页内滚动、PDF 缩放、答案展开与引用。页面切换不重置这些状态；阅读位置、滚动、缩放和答案状态通过 012 保存到本机；待发送引用继续由当前窗口管理。

重命名气泡显示原名称，支持保存、取消及按 Escape 关闭。名称去除首尾空白后为 1–100 个字符。新对话默认名为“新对话”，首次提问取问题前 24 个字符作为标题；示例使用预设标题。标题由 SolveMate 管理，用户改名时按[006](../006-ai-conversation-metadata/spec.md)中各适配器支持的范围同步第三方名称。手动命名后不再由后续提问覆盖；重命名不改变会话编号、消息、阅读关联、归档状态或外部绑定。进行中和已归档条目均支持重命名。

## 验收标准

- 阅读位置停在 M001 时从机器人页面创建对话，列表显示“普通对话”，输入框没有阅读关联；发送并刷新后仍保持普通对话。从阅读页另行提问时，关联当前阅读内容，且不改变普通对话的记录。
- 两组默认展开状态正确；进行中列表很长时，归档标题仍可见；两组均可独立展开、收起。
- 重命名、标签选择、自定义标签、归档／移回进行中和删除生效，刷新后保存结果仍保留；旧会话显示“无标签”。
- 归档后输入框、推荐问题和重新提问入口隐藏，刷新后仍保持；右键选择“移回进行中”后恢复提问入口并沿用原对话。
- 重命名、修改标签或归档不改变 session ID、消息、内容关联或外部对应关系；删除当前会话后不再显示其记录，也不会将新问题写入已删除会话。

- 高等数学 24 道题、C 语言 12 道题均能按学科选择并展示，题干、公式和代码内容完整可读。
- 桌面端从左到右展示窄菜单栏、题目栏和聊天栏。
- 点击“学科”进入统一选择页面；学科列表、学习资料／题目切换和条目数量清楚对齐，选择条目后打开对应正文。底部“系统设置”点击后显示一级气泡，显示设置和 AI 配置分别打开对应的二级气泡，社区内容进入下载管理页。
- 点击“学科”后显示学科、学习资料／题目和条目列表；选择条目后打开对应 PDF 或题目，返回按钮可回到同一列表。
- 在统一选择页面切换到“题目”后，右侧显示当前学科的题目集与数量；打开题目后，上一题／下一题、答案开关和返回列表入口均可使用。
- 聊天栏初始提示语与页面布局中的约定一致。
- 点击头像可进入账号设置，未开放的入口不可点击。
- 点击“对话”能查看会话列表，选择已有会话后可见对应历史消息和关联内容；继续发送的消息保留在所选会话，切换会话后不混入其他会话的消息。
- 点击“笔记”切换为独立页面，中间以“笔记本 → 条目”组织内容。点击笔记本展开或收起，点击条目后右侧显示对应正文；来源从笔记条目标题后的入口查看，不把学科标签重复写进正文。收起笔记本不清空正文。
- 点击“机器人”切换为配置页面，可分别选择“全科教师”“高数教师”“C 语言教师”，修改并保存各自配置，也可创建新机器人；选择“使用此机器人”后进入关联该机器人的普通对话，不继承后台阅读位置。
- 用户可自建名为“英语教师”等机器人，在角色指令中说明专业侧重；选它创建数学会话时不受限制。角色设定只显示名称、角色指令两个输入项，支持保存、取消或恢复默认。
- 预置机器人和新建机器人采用统一的通用角色指令，要求准确理解问题、针对性回答、表达清楚并如实说明不确定之处，不强制按概念、定义、条件、推导的固定顺序展开。“高数教师”与“C 语言教师”保留各自的专业要求。旧预置指令未被用户修改时自动更新；用户自己的角色指令、其他配置和历史执行记录保留。
- 机器人配置右下角依次提供恢复默认、取消修改、保存配置；取消恢复上次保存内容，恢复默认需再次保存才持久生效。草稿与提示按机器人独立管理，改回已保存值后提示消失，无修改时取消和保存不可点击。
- 机器人条目的右键菜单可设默认、复制和删除；新建对话使用默认机器人，已有会话不随默认选择改变，复制后的配置可独立修改。删除机器人不改变历史回复归属；删除全部后仍可重新创建。
- 答案显示开关可以显示和隐藏当前题目的参考答案。
- 普通对话、阅读页与教研室均不展示推荐栏。
- 聊天栏顶部可选择已配置机器人，配置页新增或改名保存后选项同步；已有对话切换机器人时先确认并创建新对话，原对话的消息和机器人关联不变。
- 聊天栏不显示“正在阅读资料”等重复状态文字，推荐区域默认收起，展开后展示两条问题。
- 切换题目后，不把旧题的推荐问题继续作为当前题目的推荐内容。
- 打开 M001 后只输入“为什么要有理化？”，生成讲解所使用的上下文包含 M001 的题干与本次询问，无需用户复制题干。
- 在同一道题连续追问时，生成回答所使用的上下文包含必要的前文，并能解释用户所指的步骤。
- 从 M001 切换至 M005 后，新询问关联 M005，不能仍将 M001 作为当前题目。
- 页面支持纯文字提问，不依赖上传资料才能使用。
- 页面不要求点击“已理解”“已解决”或类似按钮，也不把学习成功判定作为结束条件。
- 回复返回后能够正常展示；请求失败时显示明确状态。
- 完成初次加载和内容下载后，屏蔽 SolveMate 社区服务并重新打开页面，仍可阅读已下载内容和已保存历史。
- 在社区服务不可达、已配置 API / harness 可达时，询问和追问仍可进行；AI 连接不可达时有明确提示。
- 关闭并重新打开页面后，会话和机器人配置可恢复；内容更新失败保留旧内容。
- 验收围绕上述可观察的软件行为进行，不要求证明学生已经学会。

### 返回阅读后的引用验收

- 从对话条目返回后进入同一个阅读页面，统一选择区定位到对应学科和学习资料或题目；网页刷新后仍默认进入对话页。
- PDF 与题目均可选择文字并确认添加到聊天。点击空白处取消临时选区，已添加引用不受影响；保存的消息包含实际添加的全部片段。
- 同一次打开应用期间切换功能再返回，恢复对应阅读场景中尚未发送的引用；题目分别保存，PDF 各页共用，删除一条不影响其他片段。

- 展开题目答案并滚动后，切换笔记、对话或其他内容再返回，答案、滚动和已添加引用一并恢复；从学科列表重开同一内容使用相同记录。不同题目和资料版本分别保存位置状态。
