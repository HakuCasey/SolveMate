# 014 状态栏与资料上传进度

## 背景与目标

用户需要确认修改是否保存、应用是否可更新，以及 AI 是否仍在回复。资料上传后还要等待解析或转换，窗口应显示实际进度与结果。

## 状态栏

右下角固定三列，顺序为记录保存、应用更新、对话状态。详细说明和操作在各自气泡内展示，状态栏不常驻目录位置、离线资源或资料转换说明。

| 列 | 空闲状态 | 处理与异常状态 |
| --- | --- | --- |
| 记录保存 | 已保存 | 正在保存…、有未保存修改、保存失败；服务不可达或读取失败时显示具体状态 |
| 应用更新 | 检查更新 | 正在检查…、正在下载…、新版就绪、正在更新…、更新失败 |
| 对话状态 | AI 空闲 | 正在回复…、等待确认、回复失败；多项同时回复时显示数量 |

- 记录保存气泡保留错误、重试保存、刷新和未保存内容入口。当前表单修改与历史草稿分开判断，不把草稿备份当作正式保存。
- 新版下载完成后，状态栏自动显示“新版就绪”，使用主题强调色、浅色底与上箭头图标突出显示，不依赖用户打开气泡。用户在气泡中点击“更新应用”后才启用新版。
- 三列气泡共用同一结构：第一行在保存、下载或对话图标后加粗显示“记录保存”“应用更新”或“对话状态”，第二行显示当前状态，字号统一为 13px。下面仅在存在操作时显示按钮或对话入口，失败时保留具体原因。不重复解释已保存、空闲、已是最新等状态，不放装饰性大图标或额外的资源就绪说明。日间、夜间与各色调使用同一套主题变量。
- 应用更新气泡保留检查、更新及失败重试；浏览器提供安装提示时显示“安装应用”。应用仍自动检查更新。
- 对话状态覆盖所有尚未删除的对话。切换页面不丢失生成状态；点击任务恢复原对话及关联资料。失败提示可关闭，不改变对话记录。
- “刷新数据”放在设置中。窗口获得焦点、恢复可见或恢复网络时合并刷新，不每 15 秒读取全部业务记录。资料处理和 AI 回复按各自任务继续获取进度。

## 资料上传

- 上传窗口增加“上传与处理”步骤。逐文件显示实际上传字节；达到 100% 后仍等待服务确认保存。
- 解析、转换使用持续进度条，不编造百分比。总进度按已有最终结果的文件数量计算，失败单独标出。
- 保存原件后窗口保持打开，直到用户关闭或完成。网络上传未结束时不能关闭；上传结束后可关闭，资料列表继续显示处理状态。
- 失败给出原因：传输失败重试对应文件，处理失败重试已有原件，不重新上传成功文件。无法读取最新进度时提供刷新操作。

## 验收

1. 未保存表单、保存失败、配置提交成功与恢复后，记录保存列显示实际状态，原输入保留。
2. 不点击状态栏时，后台下载完成也会自动高亮“新版就绪”；气泡中的“更新应用”可启用新版。自动更新检查、安装入口条件和重载前输入保护仍有效。
3. 回复中切换页面、返回对话、停止生成及权限确认时，第三列与实际任务一致。
4. PDF 与 PPTX 上传后显示解析或转换结果；处理失败可重试，成功文件不重传。
5. 日间与夜间状态栏、气泡和上传进度均可读；测试使用独立数据，不调用真实 Codex。
