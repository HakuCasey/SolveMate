# 003 AI 配置与 DeepSeek Harness 接入

## 目标与背景

用户在 SolveMate 中完成 AI 配置，使用电脑上已经安装的 DeepSeek Harness 进行真实提问、追问，并在重新打开网页或重启本机服务后继续原会话。SolveMate 管理学习界面与本地记录，模型调用和工具执行由 Harness 完成。

本特性涉及 AI 管理和数据管理，并使用资料阅读提供的现有教材或题目内容。用户文件导入、PDF 呈现和选段交互继续单独设计，本特性不表示这些功能已经交付。

## 用户交互

### 全局 AI 配置

入口沿用“设置 → AI 配置”的气泡。

1. AI 服务默认为“未配置”。用户选择“DeepSeek Harness”后，显示“检测连接”按钮。
2. 通过 PATH 查找 `dsh` 命令；命令缺失时显示安装路径输入框，自动填入当前系统的默认安装路径并尝试一次连接。默认位置仍找不到程序时，提示用户填写实际路径，不另设“自动查找”按钮。手动路径不会被默认值替换。界面不要求用户输入命令参数，也不使用 shell 拼接命令。
3. 检测连接检查本机服务、程序版本、ACP 能力与模型列表，不发送问题给模型。检测中禁止重复操作，失败时保留填写内容并给出可处理的原因。
4. 检测成功后，模型从 Harness 实际返回的选项中选择；存在推理强度选项时才显示，不编造模型名称或不支持的参数。
5. “保存配置”确认本次配置；“取消修改”恢复已保存值。未通过检测的程序配置不能保存为可用连接。
6. 服务停止、路径失效或模型调用失败时，保留原有资料和对话，通过状态和错误提示引导重新检测。

保存按钮不可用时，气泡内显示具体原因；检测与保存分别显示进行状态。AI 服务、模型和推理强度的选项列表跟随白天、夜间外观，并支持键盘操作。

检测复用同一 DSH 配置目录中的桌面自定义模型提供方，同时保留 ACP 已有配置。无法读取或解析模型配置时显示原因，不把不完整列表作为检测成功结果。

连接检测成功仅说明协议和模型列表可用；模型的鉴权、额度与实际响应在首次提问时确认。模型凭据由 Harness 自身管理，SolveMate 不读取、展示或复制其密钥。

### 机器人 AI 配置

- 机器人页面和聊天栏入口编辑同一机器人的 AI 配置，保存后两处同步。聊天气泡每次打开都读取当前对话实际使用的配置，本次未保存或未确认的选择不带入下次打开。
- 支持跟随全局配置或单独选择模型；跟随全局时显示实际 Harness 与模型，不使用空白占位。
- 聊天入口与机器人条目显示“服务名称 | 模型名称”；未配置全局 AI 时，聊天入口的模型名称留空、保留配置标记，在入口下方与配置区显示红字提示。
- 聊天气泡只保存或取消 AI 字段，其他未保存的角色输入保留；保存后适用于使用该机器人的其他对话的后续提问。
- 单独配置也使用已检测连接的真实模型列表；保存后的选择用于后续提问。
- Harness 没有提供的温度等参数不能表现为已经生效。既有记录保留，不因本特性删除用户配置。
- 教师名称和角色指令继续由 SolveMate 管理，随本次问题传递。ACP 文本中的角色要求不等同于模型系统消息。

### 提问与恢复

- 普通会话可以直接提问；阅读会话同时传递当前关联教材章节或题目的实际文字，显示本次资料引用。
- 教师、模型和资料引用在每轮发起时确定。随后切换页面或机器人不改写历史消息。
- 学生问题和教师回复以左右、底色不同的气泡展示。提问后立即出现教师等待气泡，展示真实执行状态与用时；状态、权限和错误跟随回复显示，不作为教师回答正文保存。
- 网页实时接收执行快照，收到多少正文就显示多少；断线后按原请求编号恢复，不重复提交，不将整段答案伪装成逐字生成。DSH 当前 ACP 不提供提供方原始文本增量，实际时序见设计验证记录。
- 生成期间提供“停止”。失败后保留问题与已收到的内容，允许重试；对可能已经执行的请求不自动重复发送。
- 一个会话同时只允许一轮执行；不同会话分别管理。
- 已有示例内容继续标为示例；真实回复必须来自实际调用。
- 网页刷新后能读取本地记录；本机服务重启后依据保存的绑定恢复外部会话。恢复失败时明确提示，不静默创建空会话冒充恢复成功。
- 不依赖 Harness 回放历史消息。历史展示由 SolveMate 自己保存的消息提供。

## 多服务接入中的对话切换规则

以下规则由 [004 Hermes 接入与多服务会话管理](../004-hermes-harness-adapter/spec.md)实现，保留在此说明与首项接入特性的关系。

| 操作                       | 确认提示                                                      | 确认后的行为                                       |
| -------------------------- | ------------------------------------------------------------- | -------------------------------------------------- |
| 切换教师                   | 切换教师后对话重新开始，请确认是否切换？                      | 使用所选教师开始新对话                             |
| 切换模型，Harness 服务不变 | 不弹确认框                                                    | 保留当前对话及其外部 session，后续提问使用所选模型 |
| 切换 Harness 服务          | 当前操作会切换 Harness 服务，对话将重新开始，请确认是否切换？ | 使用所选服务开始新对话                             |

确认框提供“确认”和“取消”。取消时保持原选择、当前对话及外部 session 不变，不创建新会话。确认开始新对话时，保留原对话的消息、教师和外部会话绑定；新对话不继承旧聊天消息，也不复用旧 session。外部 session 在新对话首次实际提问时创建，避免仅切换选项就在 Harness 中留下空会话。历史消息保留当时的教师和模型记录。

- [x] 切换教师前显示指定提示，验证确认与取消的行为。
- [x] 切换 Harness 服务前显示指定提示，验证确认与取消的行为。
- [x] 切换同一 Harness 内的模型时，不弹重开提示、不创建新 session。
- [x] 确认后可重新打开原对话；取消或重复选择同一项不改变会话绑定。

## 范围边界

本特性首先实现 DeepSeek Harness ACP；Hermes 由 [004](../004-hermes-harness-adapter/spec.md)接入，Codex 由 [005](../005-codex-harness-adapter/spec.md)接入，其他 API 与 Harness 尚未支持。模型、推理选项和恢复能力以实际运行时返回结果为准。桌面端插件、登录态、文件处理及内部会话不能仅凭安装成功认定可复用。通过断网场景验证的是脱离 SolveMate 官方内容服务，模型自身仍须可达。
