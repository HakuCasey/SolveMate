# 003 AI 配置与 DeepSeek Harness 接入

## 目标与背景

用户在 SolveMate 中完成 AI 配置，使用电脑上已经安装的 DeepSeek Harness 进行真实提问、追问，并在重新打开网页或重启本机服务后继续原会话。SolveMate 管理学习界面与本地记录，模型调用和工具执行由 Harness 完成。

本特性涉及 AI 管理和数据管理，传递资料阅读提供的 PDF 页、选段或题目文字。用户文件导入与 PDF 呈现由 007 负责。

## 用户交互

### 全局 AI 配置

入口沿用“设置 → AI 配置”的气泡。

1. AI 服务下拉框列出适配器支持的服务，每项只显示“已连接”或“未连接”。选择服务后可检测连接；检测成功即进入已连接，失败保留路径及原有模型目录，并提供重试。
2. 通过 PATH 查找 `dsh` 命令；命令缺失时显示安装路径输入框，自动填入当前系统的默认安装路径并尝试一次连接。默认位置仍找不到程序时，提示用户填写实际路径，不另设“自动查找”按钮。手动路径不会被默认值替换。界面不要求用户输入命令参数，也不使用 shell 拼接命令。
3. 检测连接检查本机服务、程序版本、原生接口与模型列表，不发送问题给模型。检测中禁止重复操作，失败时保留填写内容并给出可处理的原因。
4. 检测成功后，模型从 Harness 实际返回的选项中选择；推理等级有实际选项时才能选择；没有选项时保留该行，显示“暂无可选等级”并禁用下拉框，不编造模型名称或不支持的参数。
5. 检测成功后本机统一保存连接与模型目录，不提供启用、停用或单独的断开连接按钮；删除配置时释放本应用持有的连接与进程。安装路径等配置修改后需重新检测；“保存配置”保存其余选项，“取消修改”恢复已保存值。未通过检测的程序配置不能作为已连接使用。
6. 服务停止、路径失效或模型调用失败时，保留原有资料和对话，通过状态和错误提示引导重新检测。

删除配置的确认框不关闭 AI 配置或上层设置气泡；取消后返回原按钮，删除成功后返回服务选择框，所选服务保留并显示未连接。

连接状态只在 AI 服务下拉框中显示，不另起“当前状态”一行。模型和推理等级各占一行，左侧为标签，右侧为普通下拉框，两行对齐，不添加共用的灰色底块。底部按钮依次为“设为默认”“取消修改”“保存配置”，尺寸一致；默认按钮只在连接和所选模型有效时可用。当前选择已是全局默认模型时显示“已默认”，没有默认模型时显示“当前未设置全局默认模型”。

保存按钮不可用时，气泡内显示具体原因；检测与保存分别显示进行状态。AI 服务、模型和推理强度的选项列表跟随白天、夜间外观，并支持键盘操作。

检测复用同一 DSH 配置目录中的桌面自定义模型提供方，同时保留 ACP 已有配置。无法读取或解析模型配置时显示原因，不把不完整列表作为检测成功结果。

连接检测成功仅说明协议和模型列表可用；模型的鉴权、额度与实际响应在首次提问时确认。模型凭据由 Harness 自身管理，SolveMate 不读取、展示或复制其密钥。

### 机器人与对话的 AI 选择

- “设置 → AI 配置”使用 CPU 图标，管理外部服务连接与全局默认模型；机器人页面和聊天栏的“AI 选择”使用大脑图标，只从已连接服务中选择服务、模型及推理等级。两者读取相同的连接和模型目录。聊天气泡每次打开都读取当前对话实际使用的配置，本次未保存或未确认的选择不带入下次打开。
- 支持跟随全局配置或单独选择模型；跟随全局时显示实际 Harness 与模型，不使用空白占位。
- 聊天入口与机器人条目显示“服务名称 | 模型名称”；未配置全局 AI 时，聊天入口的模型名称留空、保留配置标记，在入口下方与配置区显示红字提示。
- 聊天气泡只保存或取消 AI 字段，其他未保存的角色输入保留；保存后更新机器人默认选择及当前对话，不改写其他对话。
- 单独选择使用已连接服务的真实模型及推理等级列表；保存后用于后续提问。机器人页面修改默认选择只影响新对话。
- Harness 没有提供的温度等参数不能表现为已经生效。既有记录保留，不因本特性删除用户配置。
- 教师名称和角色指令继续由 SolveMate 管理，随本次问题传递。提问文本中的角色要求不等同于模型系统消息。

### 提问与恢复

- 普通会话可以直接提问；阅读会话同时传递当前关联教材章节或题目的实际文字，显示本次资料引用。
- 教师、模型和资料引用在每轮发起时确定。随后切换页面或机器人不改写历史消息。
- 学生问题和教师回复以左右、底色不同的气泡展示。提问后立即出现教师等待气泡，展示真实执行状态与用时；状态、权限和错误跟随回复显示，不作为教师回答正文保存。
- 网页实时接收执行快照，收到多少正文就显示多少；断线后按原请求编号恢复，不重复提交，不将整段答案伪装成逐字生成。DSH 原生接口提供生成中的正文增量，由适配器按原生序号去重，并用持久化消息校正；思考只显示状态，不展示原始思考正文。
- 生成期间提供“停止”。失败后保留问题与已收到的内容，允许重试；对可能已经执行的请求不自动重复发送。
- 停止请求发出后显示“正在停止”，等待 Harness 结束本轮。Harness 可以在确认停止前返回已生成的内容，应用保留这些内容；已取消的回答显示“已停止”及内容可能不完整的说明，继续提问后仍可识别该回答的状态。
- 一个会话同时只允许一轮执行；不同会话分别管理。
- 已有示例内容继续标为示例；真实回复必须来自实际调用。
- 网页刷新后能读取本地记录；本机服务重启后依据保存的绑定恢复外部会话。恢复失败时明确提示，不静默创建空会话冒充恢复成功。
- 不依赖 Harness 回放历史消息。历史展示由 SolveMate 自己保存的消息提供。

### DSH 实时执行与故障处理

- 每个正在处理的原生会话使用独立 Host；生成、等待权限和订阅重连期间保留，结束或停止确认后释放。网页刷新或切换页面不结束任务。
- 模型选择不更改 DSH 的默认设置；用户无需另建 profile、重新登录或逐轮检测连接。
- 一次执行使用稳定请求编号。订阅断线最多重连三次，恢复已生成内容与后续增量，不重新发送问题。
- 权限仅提供一次性允许和拒绝。原生撤销请求时同步关闭本地确认；权限等待期间断线或决定未能送达时中断本轮，不自动授权，保留问题、正文与原绑定。
- Host 意外退出时显示中断，不禁用整个连接、不另建原生会话；下次仍由适配器查找原编号。原会话明确不存在时按已有确认流程处理。
- 停止未能确认时，限时关闭本应用创建的进程并说明中断，不能将取消请求被接受当作正常停止完成。

## 多服务接入中的对话切换规则

以下规则由 [004 Hermes 接入与多服务会话管理](../004-hermes-harness-adapter/spec.md)实现，保留在此说明与首项接入特性的关系。

| 操作                               | 确认提示                                 | 确认后的行为                                         |
| ---------------------------------- | ---------------------------------------- | ---------------------------------------------------- |
| 切换教师                           | 切换教师后对话重新开始，请确认是否切换？ | 使用所选教师开始新对话                               |
| 切换模型，Harness 服务不变         | 不弹确认框                               | 保留当前对话及其外部 session，后续提问使用所选模型   |
| 尚未提问且未建立原生会话时切换服务 | 不弹确认框                               | 只保存服务、模型及推理等级选择，不建立原生会话       |
| 首次使用另一项 Harness 服务        | 更换 AI 服务需要重新发起会话，是否发起？ | 保留当前对话及消息，首次提问时建立目标服务的原生会话 |
| 切回已有原生会话的服务             | 将继续该 AI 服务中的原会话，是否切换？   | 保留当前对话，恢复目标服务原编号并补充尚未收到的内容 |

确认框提供“确认”和“取消”。取消时保持原选择、当前对话及各服务的原生会话关联不变。切换机器人创建新对话，保留原对话的消息和原生关联；切换服务保留当前对话及消息。目标服务尚无原生会话时，在首次实际提问时创建，避免仅切换选项就在 Harness 中留下空会话；已有原生会话则恢复原编号。历史消息保留当时的机器人和模型记录。

- [x] 切换教师前显示指定提示，验证确认与取消的行为。
- [x] 切换 Harness 服务前显示指定提示，验证确认与取消的行为。
- [x] 切换同一 Harness 内的模型时，不弹重开提示、不创建新 session。
- [x] 确认后可重新打开原对话；取消或重复选择同一项不改变会话绑定。

## 范围边界

DeepSeek Harness 通过本机原生 Host 接入实时正文、停止与权限确认，沿用已有 ACP 会话编号；Hermes 由 [004](../004-hermes-harness-adapter/spec.md)接入，Codex 由 [005](../005-codex-harness-adapter/spec.md)接入，其他 API 与 Harness 尚未支持。模型、推理选项和恢复能力以实际运行时返回结果为准。桌面端插件、登录态、文件处理及内部会话不能仅凭安装成功认定可复用。通过断网场景验证的是脱离 SolveMate 官方内容服务，模型自身仍须可达。

所有 Harness 共用服务下拉、连接操作、模型与推理等级组件，状态与模型目录读取同一条后端连接元数据。未连接时不展示可操作的模型、默认和推理等级控件；保留的数据在检测成功后恢复展示。选择模型不触发连接检测，推理等级只展示当前模型已实际返回的选项。需要专用检测会话的适配器在删除配置后使用新的检测记录，普通检测复用；DSH 使用不依赖会话的模型目录接口，不创建或恢复检测会话。

## 保存消息与重试回复

点击提问后，先保存消息、引用与本次尝试，再判断是否提交 AI。新对话与已有对话采用同一规则；未配置 AI、连接已删除或模型不可用均不阻止消息保存，页面说明未提交原因。保存成功后清空本次输入和已发送引用；保存失败则保留输入，不发出 AI 请求。归档只读和数量限制继续有效。

“重试回复”使用原消息的稳定编号、正文和引用，创建新的执行尝试，不追加重复问题，不消耗当前未发送的输入或引用。旧执行和已收到的部分回复保留。请求是否被接收尚不确定时，只按原执行编号查询；明确查无记录或明确拒绝后才允许手动重试。已完成的请求不通过失败重试入口再次提交。
