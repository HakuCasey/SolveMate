# AI 配置一致性测试

## 目标与边界

验证配置保存、背景刷新、删除和重新连接交错发生时，各入口仍显示同一份有效配置；保留未保存输入及历史会话关联。

自动测试使用临时数据库、模拟 Harness 和专用网页地址，不访问用户运行数据，不创建真实第三方会话，不调用真实模型或 Codex。macOS、Windows 路径与命令启动分别覆盖；本机执行不能替代 Windows 实机验收。

## 测试设计

| 编号 | 场景与触发条件 | 检查结果 | 验证方式 |
| --- | --- | --- | --- |
| C01 | 选择模型和推理等级，设为默认，再保存；重复保存 | 路径、模型、推理等级仍可见，不出现路径更改提示；未重新建连 | 后端临时存储测试、网页交互 |
| C02 | 安装路径分别为自动查找、macOS 应用路径、Windows 程序路径；实际可执行路径与输入不同 | 配置保留输入路径，检测结果保留实际路径 | 后端参数化测试 |
| C03 | 保存成功后，返回保存前取得的旧配置；反向交换返回顺序 | 最终保留新版本中的路径、模型及等级 | 共享状态测试、网页延迟响应 |
| C04 | 编辑模型期间刷新；只修改推理等级时刷新 | 未提交字段保留，未编辑字段显示当前共享值，不误报路径更改 | 网页交互 |
| C05 | 修改路径、取消修改、重新检测 | 仅真实路径改动要求检测；取消恢复保存值；检测后恢复模型选择 | 网页交互、后端测试 |
| C06 | 保存失败、版本冲突或网络错误 | 保留输入，不提示成功；核对最新记录后可重新保存 | 后端冲突测试、网页错误响应 |
| C07 | 删除连接后返回旧读取；删除后重连再返回删除时的快照 | 不复活旧连接，不清除重新连接的配置；默认引用按规则清除 | 共享状态、后端、网页交互 |
| C08 | 全局配置变化后进入对话栏、机器人配置，再返回 | 服务和模型选项来自同一目录；不可用选择清空并说明原因 | 配置解析测试、网页交互 |
| C09 | 全局默认改变，机器人存在独立选择，历史对话已有模型及会话编号 | 未独立配置的入口跟随默认；独立选择及历史绑定保持原值 | 配置解析、会话恢复测试 |
| C10 | DSH 反复检测，检测失败、超时、取消及进程退出 | 查询模型目录不新建用户会话；只清理自建资源；失败可重试 | 适配器、目录服务与进程测试 |
| C11 | 取消回复后返回已生成内容，随后继续提问 | 保留真实内容和原会话；旧回答仍显示停止状态，不自动重发问题 | 后端取消测试、网页交互 |
| C12 | 日间与夜间、键盘选择模型、服务无推理选项 | 表单布局、选项、提示和可操作状态一致，无重复状态说明 | 网页检查 |

## 执行要求

先完成上述设计对应的实现，再运行专项测试与仓库检查。修复失败后重复受影响的测试，最后对实际提交内容重新运行检查、测试和构建。测试记录区分模拟结果、真实 Harness 结果和未验证项目，不用构建成功代替交互验证。

测试发现并修正了旧默认模型引用在目录不足时丢失、模型级推理选项未归一化，以及下拉控件不接受空值选项的问题。旧启停规则相关的测试已改为检查连接状态、资源释放、失败后的重新检测和原会话恢复。

本次未启动真实 Harness 或调用模型，未访问用户正式数据。两项跳过分别为 Windows 原生 Shell 目录接口和未配置真实调用参数的 Harness 用例；Windows 实机安装与调用仍未验收。窗口测试使用独立地址及模拟记录，不将模拟结果表述为第三方产品的真实调用结果。

## 保存状态、服务顺序与气泡

2026-11-13，使用独立的模拟连接服务和 Chrome 验证：

- 初次打开、刷新后重新打开、改回原值、取消修改及保存成功后，保存与取消按钮禁用。
- 模拟保存失败后，模型及推理等级保留，保存按钮仍可重试；重试成功后禁用。
- 全局默认切到 Hermes 后重新打开管理气泡，仍先显示支持目录第一项 DSH；机器人选择按实际配置显示。
- 检测按钮统一显示“检测连接”；检测期间持续显示等待秒数，完成后恢复按钮。
- 日间、夜间模式使用相同的气泡外框、标题图标和间距。学习时长与记录保存详情复用同一组件；AI 配置宽度为 360px，受窗口边界限制时正文可以滚动。

服务排序另有单元测试，连接记录顺序变化及删除第一项连接均不改变支持目录。

提交文件单独导出后通过 TypeScript、ESLint、Prettier、Ruff、构建与 19 项脚本测试、295 项前端测试、239 项本机服务测试；另 2 项按运行条件跳过。
