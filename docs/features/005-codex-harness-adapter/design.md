# Codex app-server 适配设计

## 接入方式

使用 `codex app-server --listen stdio://`。本机已安装的 Codex CLI 为 0.162.1，模型、登录状态与配置由该进程提供；SolveMate 不读取凭据文件。官方文档与安装版本生成的 JSON Schema 共同用于核对请求和事件。

## 适配边界

DSH 与 Hermes 使用 ACP，Codex 使用 app-server。公共服务只管理连接、绑定、执行状态和保存；启动、检测、创建与恢复会话、模型与推理选项、提问、停止和权限响应均经适配器调用。

会话结果统一提供稳定编号与模型选项；事件统一表示正文、正文校正、思考状态、工具状态和原生执行编号。ACP 与 app-server 的方法名和原始通知留在各自适配器中。JSON-RPC 传输层共用子进程、收发、超时和退出处理。

Codex 的连接编号为 `codex-local`，绑定协议为 `codex-app-server`。已有 DSH、Hermes 编号和数据库结构保持不变。注册表接收适配器集合，测试通过注入适配器隔离不同服务，不为每个新服务追加一组构造参数。

## Codex 行为

- 初始化后发送 `initialized`，通过 `account/read`、`config/read` 和分页 `model/list` 检测。无需检测会话。
- `thread/start` 创建正式 thread；`thread/resume` 严格恢复原编号。首次实际提问前不创建 thread。
- 模型和推理强度随 `turn/start` 传入；在原 thread 内更换模型。使用原生 `turnId` 发送 `turn/interrupt`。
- 确认 `turn/start` 返回的执行编号后才接受对应事件，防止把同一原生 thread 中其他客户端的回复混入本轮。
- `item/agentMessage/delta` 提供实际增量，`item/completed` 校正最终正文；按 item 编号合并并避免重复。思考事件只更新状态。
- 权限决定仅作用于当前操作或当前轮次，不自动选择会话级授权。无法处理的客户端请求明确返回不支持，不静默等待。
- 原生失败、中断、断线和超时分别保存实际状态；不自动重复提交结果未知的提问。

## 变更范围

| 范围       | 实现位置与职责                                                                                                          |
| ---------- | ----------------------------------------------------------------------------------------------------------------------- |
| Codex 协议 | 新增 `adapters/codex.py`、`adapters/codex_process.py`，负责 CLI 发现、检测、thread/turn、模型、正文和权限               |
| 公共数据   | 新增 `adapters/types.py`，定义会话编号、模型选项及执行事件                                                              |
| 公共服务   | `service.py`、`connections.py` 使用适配器方法和统一结果；公共服务不再调用 ACP 方法或解释原生通知                        |
| 传输       | `transport.py` 共用 JSON-RPC 收发与生命周期，ACP、app-server 分别初始化和处理原生客户端请求；读任务结束后不复用失效连接 |
| 注册与兼容 | 注册 Codex，声明服务类型；旧格式迁移只处理 DSH，不把新服务写成 DSH 连接                                                 |
| 前端       | 仅调整 `ai/local-api.ts`、`ai/robot-config.ts`、`ai/state.ts`，声明服务并保存原生协议与执行编号                         |
| 业务页面   | 聊天页面、教师配置页面、AI 配置气泡、服务切换确认及列宽布局均复用现有代码，无文件改动                                   |

公共接口补充了提问、停止、权限、事件和运行状态检查。DSH、Hermes 的协议转换放在 ACP 适配器中；新服务通过注册适配器与声明类型加入。对现有接口无法表达的操作，应明确扩展公共接口并验证已有服务。

## 模型与权限边界

模型目录使用分页 `model/list`，保留 Codex 配置中的当前模型。自定义模型未出现在目录时仅补充该模型，不推测其他自定义模型或其推理选项。目录、登录状态和真实推理分别验证。

权限按原生接口的最小范围提交：命令、文件修改只批准本次；权限配置只批准本轮，不提供会话级授权。文件修改提示包含原生 item 中的文件路径。操作内容超过本页可完整显示的长度时仅提供拒绝；其他客户端执行的请求不会进入本轮授权。
