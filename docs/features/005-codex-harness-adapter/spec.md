# 005 Codex 接入与跨协议适配

## 目标

通过本机 Codex CLI 的官方 app-server 接口复用已有登录、模型配置和原生 thread。Codex 与 DSH、Hermes 使用相同的对话界面和管理规则。

## 范围与验收

- 设置中可选择 Codex，检测登录与模型目录，选择模型和推理强度后保存。模型编号与选项以运行时返回结果为准。
- 检测只读取配置、账号状态与模型目录，不创建 thread，不请求模型，也不读取或复制凭据。
- 首次提问建立原生 thread，追问与本机服务重启后恢复同一编号。读取或恢复失败时保留原绑定，不另建 thread。
- 正文按实际增量显示，最终消息可以纠正增量结果；不会重复显示同一段正文，不展示思考正文。支持停止与当前操作的一次性权限确认。
- 同一 Codex thread 可以换模型；切换教师或 Harness 服务继续使用已有确认与新对话规则。
- 页面、教师配置、对话绑定和执行快照共用现有实现，不新增一套 Codex 页面或会话管理。
- DSH 与 Hermes 通过回归测试；记录新增服务涉及的代码范围，明确本次补齐了哪些适配边界。
- Windows 完成启动参数、路径和协议的自动测试；真实安装与账号调用仍待实机验收。

本特性不包含 Codex 历史列表导入、原生标题与归档同步、登录界面、Skill 安装或文件导入。不改变用户的全局 Codex 配置或桌面应用状态。
