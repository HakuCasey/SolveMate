# 016 机器人配置导入与统一导出

## 范围

机器人右键提供“导出配置”，机器人页面提供“导入配置”。机器人导出 JSON，笔记本导出 PDF。两个导出入口共用窗口和保存规则，不包含 AI 连接凭据、程序路径或对话记录。

## 导出

- 标题分别为“机器人导出”“笔记本导出”，显示对象名称、文件名和保存位置。
- 默认文件名为 `<名称>_<YYYY-MM-DD>.json` 或 `<名称>_<YYYY-MM-DD>.pdf`，使用本地日期；允许修改名称，扩展名固定。
- 默认保存到本机下载目录，支持选择其他目录；浏览器未开放目录选择时仍可导出到下载目录，并说明限制。
- 确认后禁用重复提交，按钮显示“导出中… xxs”。导出成功后显示结果，3 秒后关闭；失败保留文件名和位置，可以重试。取消不删除已有文件。
- 同名文件不覆盖，自动添加数字后缀；用户主动选择覆盖不在本特性范围内。
- 机器人导出已保存配置，不把尚未保存的表单输入当成正式配置。

## 导入

- 接收 SolveMate 导出的 JSON，检查格式标识、版本、文件大小和完整机器人元数据。
- 导入产生新的机器人编号，不覆盖原记录，不改变已有全局默认或历史对话。重名时加“导入”后缀。
- 保留名称、角色指令、外观、AI 选择与记忆／能力设置。文件中的服务与模型引用不会建立外部连接；本机没有对应连接时，通过现有 AI 选择界面提示重新配置或选择。
- 保存成功才显示新条目；解析或保存失败显示原因，已有机器人和草稿保留。


机器人名称在保存时检查重名，比较时去除首尾空白并排除当前机器人。重名时保留输入，在名称旁显示“命名重复，请重新命名。”并标红输入框。新建机器人自动使用未占用名称，复制及导入继续自动处理重名。已有记录不因增加此规则被改名或删除。

机器人列表标题单行显示图标、“机器人”和当前数量／9，数量使用次要文字颜色；标题与配置栏同高。每个本地资料目录最多新增至 9 个机器人，新建、复制、导入与本机保存使用同一上限。达到上限后相应入口不可用，提示“最多支持 9 个机器人。”。已有超限记录保留，仍允许编辑或删除，不允许继续增加数量。
