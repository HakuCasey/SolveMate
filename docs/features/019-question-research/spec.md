# 019 教研工具与资料讨论

## 目标

在教研室选择资料和工具，向 AI 说明任务要求，查看结果并继续修改。一个工具包含 Skill 和输出模板，分别规定如何完成任务、如何组织结果。

## 功能范围

- 左侧“教研室”直接进入统一页面，中间阅读资料，右侧继续使用公共对话栏。顶部在同一行并排显示“资料＋下拉框”“工具＋下拉框”，标签与选择内容使用正常字号。
- 资料从学科列表选择，也可通过同一个上传窗口新增。资料编号、文件、阅读位置和引用规则与学科页一致，不另存一份资料。
- 预置工具为讲义研发、试题研发和试题精讲，首次使用即可选择；在“社区内容”中更新、删除或重新下载。下载完成并校验通过后保存，更新失败继续使用原工具。
- 工具列表统一显示已安装的社区工具和自定义工具，不按活动再分组。工具下拉框中可选择、新建或删除工具；不提供独立的查看或编辑图标。
- 社区工具和用户工具均支持在工具条目上右键重命名，社区内容页同步显示本地名称。改名保留原编号、Skill、模板和发布版本；社区更新保留用户修改的名称。编辑 Skill 或模板仍另存为用户工具。
- 教研室下拉框与社区内容页的“使用”共用确认窗口，检查 Skill 和输出模板；没有修改时直接使用。有修改时先填写另存为名称，保存为新的用户工具并自动选中，原工具保持不变。确认期间工具被更新或删除时，提示重新选择；不直接选用尚未确认的内容。新建复用同一窗口。Skill 和输出模板分别编辑，也可导入 Markdown／纯文本文件。每份文件不超过 128 KB，正文不超过 20000 个字符。
- 取消选择或修改不改变当前选择与已保存的工具。保存失败保留窗口内的输入，成功后才关闭并切换工具。编辑期间的输入只留在当前页面，不加入操作记录或持久化草稿。
- 下载、更新、选择和删除读取同一份本地工具目录，社区内容和教研室的状态同步变化。删除工具保留已有对话，不在返回对话时重新创建已删除的工具。
- 用户消息保存发送时使用的 Skill 与模板，后续编辑不改写历史。重试使用原消息的配置；新提问使用当前已保存的配置。
- 资料阅读、页码选择、选段、笔记、会话恢复、服务切换、停止和归档复用现有实现。默认使用当前页及已添加引用；用户明确选择页码后，向 Harness 提供原 PDF 和页码范围，不声称 AI 已读取范围外的内容。

## 预置 Skill 与输出模板

- 讲义研发按资料范围与用途组织讲解，例题和练习按需安排，模板栏目可合并或省略。
- 试题研发允许设计新的情境、代码和数据，并将其明确写入题干；分别核对单选、多选的答案，检查条件充分、选项明确及解析一致。默认模板先列全部题目，再按相同题号集中给出答案与解析，每个选项单独一行。
- 试题精讲根据具体疑问确定范围，局部疑问说明原因与必要前提，其他解法、代码改写和延伸知识按用户要求展开；完整讲解才采用整题结构。参考答案需结合题目条件判断，操作与术语表述应与实际含义一致。
- 用户本次明确的输出要求优先于默认模板。修改时保留未要求修改的内容，受影响的题干、步骤、答案或解析同步调整。内容完整性与来源要求由公共 Prompt 维护。

## Skill 与模板发送

工具由本应用管理，不安装到第三方 Harness。每个原生会话分别记录最后确认收到的 Skill 和模板内容。

| 情况 | 发送内容 |
| --- | --- |
| 首次使用或重新建立原生会话 | 当前 Skill 和模板 |
| Skill、模板均未变化 | 均不重复发送 |
| 仅修改其中一项 | 只发送修改的一项 |
| A 改为 B，再改回 A | 再发送 A，因为该会话最近收到的是 B |
| 切换 AI 服务或恢复会话 | 按目标原生会话自己的接收记录判断 |
| 发送失败且没有确认接收 | 不记为已收到，后续仍需发送 |

每轮使用同一句规则说明两部分分别沿用最近提供的内容。上下文压缩后的保留与补发记入待办，本次不推断第三方是否已经遗忘内容。

## 页面文案

普通对话显示“有什么想讨论的？”及“可以提出问题，也可以说说你的理解和想法。”教研室显示“需要完成什么任务？”及“说明内容范围和具体要求，生成后可以继续提出修改意见。”推荐示例由工具提供，使用同一个对话组件展示。

## 验收重点

工具下载与编辑后可继续选择，刷新后保留资料、工具和对话。修改一个社区工具不更新其他工具或课程；失败不覆盖原版本。未修改的旧预置模板替换为三个社区工具，用户自定义模板及其技能内容继续保留。分别验证 Skill、模板变化、改回原内容、服务切换、原生会话恢复及发送失败后的补发；不改变已有会话编号和停止规则。
