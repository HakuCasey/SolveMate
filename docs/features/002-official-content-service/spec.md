# 002 官方内容目录、版本查询与下载更新

> 当前状态：当前后端与 Web/PWA 下载更新范围已实现并完成基本验证；导出备份、文件彻底删除、历史版本清理和格式扩展尚未实现。

## 涉及的模块与功能

依据[模块架构](../../architecture/overview.md#模块架构)，本特性涉及知识维护中的官方资料维护、内容发布和内容下载与更新，以及数据管理中的资料查询与读取、来源与版本管理和本地内容保存，当前资料范围为官方课程包。

本特性的已交付范围限于官方课程包及网页下载更新。发布通过维护者运行命令行工具完成；开源资料、机器人模板和 RAG 资源的维护、发布与下载尚未实现，因此架构图中相应的通用功能仍标为部分实现。

## 背景

官方课程包含教材、题目和课程记忆。客户端需要独立查询和下载内容版本，将校验通过的课程保存在本地；更新失败时保留已有可用版本。

## 目标

- 使用 Python + FastAPI，在 `apps/server` 提供课程目录、版本清单、更新判断和下载。
- 发布当前高等数学、C 语言的教材、题目、记忆点和讨论点，保留文件原文与稳定编号。
- 使查询后下载的版本保持一致，发布失败不替换已有可用目录。
- 网页支持下载、更新、校验、本地保存与离线重开，更新失败继续使用旧版。

## 非目标

- 不实现账号、个人记录同步、AI 代理、Skill 运行或 RAG 检索。

## 用户场景

维护者修改课程原文件后发布新版本；客户端查询目录和本地版本状态，获取固定版本内容包。服务不接触用户的会话与配置；无法联网时，客户端继续使用本地已有内容。

## 功能要求

1. 每门课程提供稳定编号、名称、说明、发布名称和最新版本入口。
2. 一门课程的教材、题目和课程记忆作为一个完整版本发布；下载包列出每个文件及校验值。
3. 内容包使用 SHA-256 标识版本，提供包大小、SHA-256 和固定版本下载地址。
4. 允许查询最新版本和历史版本；新发布后仍可下载旧版本，重启服务后历史版本仍保留。
5. 更新查询区分未安装、已是最新、存在已知更新和未知本地版本；未知版本不自动判断为旧版。
6. 发布前检查内容格式与引用；包完整落盘后才提交新目录。API 不提供公开发布入口。
7. 提供条件缓存、HEAD 和字节范围下载，允许网页在明确配置的来源访问。
8. 损坏包不提供下载，错误返回可区分未知记录、非法参数和发布数据不可用。

## 前端下载与本地更新

“设置 → 官方内容”分别显示学习资料与题目卡片，学科作为分类标签。高等数学和 C 语言各有学习资料及题目，共四张卡片。常规桌面宽度每行四张，窄窗口按可用宽度减少列数。每张卡片首行左侧为图标与资料名，右侧为“阅读”或“下载”等操作按钮；下面依次为简介、学科与“学习资料”或“题目”标记和更新日期。版本号、校验值和包大小不出现在卡片中。

没有有效下载记录时显示“尚未下载”和“下载”；保存完成后显示本地下载或更新日期及“阅读”。日期使用完整年月日，不与其他信息挤在一行。发现新版时显示“有新版可更新”，保留“阅读”并提供“更新”；读取或检查失败时保留已有内容，不将内置示例冒充独立下载记录。

阅读按钮打开卡片对应的学习资料或题目；已有阅读位置时保留章节或题号。官方资料与用户上传文件在学科的学习资料列表中同级展示。发布和文件保存使用课程包，每包包含学习资料、题目和记忆。每份学习资料和题目集分别保存使用中的版本、更新时间、学科归属和删除状态；同包文件可以复用，但只更新用户选中的条目。学习资料使用文档名称与简介；题目卡片显示所属学科及实际题数，打开对应题目。配套学习记忆不单独列为阅读卡片。

页面按钮使用“检查内容更新”，仅查询官方资料与题目，不触发应用更新检查。打开页面和检查内容更新时先重新读取本机版本，再查询官方服务。重新检查保留已有结果，查询结果与本地版本不匹配时不提供更新操作。连接失败仍可阅读本地课程，不将失败结果显示为已是最新。下载阶段可取消，保存事务开始后等待提交结果。

先校验 ZIP 的大小、SHA-256、文件白名单、原文件校验值和课程引用，再通过本机服务保存到 `user/community/`，由 `user/app.sqlite3` 保存版本索引。在一个事务中写入版本记录与当前版本指针，提交完成后才提示保存成功；网络中断、包损坏、取消或存储失败不替换当前版本。未知服务器版本不自动覆盖本地内容。

内置基础内容继续可用。下载后，仅所选资料的阅读入口使用该版本，其他条目保留自己的版本；旧下载版本和内置版本保留。历史会话记录课程版本，打开时保留原关联；选择“阅读”时使用已保存的新版本，并尽量保留题号或教材章节位置。下载操作不改写个人会话、笔记、机器人配置和显示设置。

## 官方学习资料 PDF

高等数学与 C 语言的学习资料统一以 PDF 阅读，使用与上传资料相同的翻页、缩放和选段控件。题目继续按题干、答案和讲解展示。PDF、逐页文字与章节页码纳入同一内容包和版本校验，选段引用记录实际页码，后续可返回原版本的原页。

Markdown 保留为内容维护源和旧版本原文，不提供章节式阅读界面。旧内容包仅在原文校验值一致时使用随应用提供的 PDF，原章节位置映射到该 PDF 的章节首页，保留原版本编号。发布时核对 PDF、页码索引和原文的校验值，不发布未同步的文件。旧的四文件内容包仍可读取；新版增加 PDF 与页码索引，不改写已有对话和笔记的版本引用。

打开官方内容页或点击“检查内容更新”后，页面显示检查结果；发现新版时显示可更新资料数量，各资料卡片显示更新提示。用户自行决定是否更新，读取旧版不触发下载；下载、校验或保存失败仍使用旧版。

## 官方资料元数据与删除联动

官方目录提供可获取的资料，本地资料对象记录用户保存的当前版本、学科归属及删除状态。学科列表、官方内容页和阅读入口使用同一资料编号与元数据，由统一的资料管理服务执行添加、下载、删除和重新添加，页面不分别保存一份业务状态。

- 用户删除官方资料，或删除包含资料的学科后，官方内容页同步更新可用状态，不再为已移除条目提供有效的“阅读”入口。
- 为历史对话保留的文件和版本不代表当前资料条目仍可使用；按钮、日期和阅读权限从统一的资料对象及文件检查结果生成。
- 重新添加官方资料后，相关列表和阅读入口同步恢复；不能连带恢复同学科中已删除的上传资料。
- 兼容现有课程包、学科删除记录和历史引用；跨窗口仍沿用已有保存版本检查与刷新机制。

在学科列表或官方内容卡片上右键，可删除官方学习资料或整套题目。删除只移除当前条目，保留课程包与历史引用；同包的其他条目不会一起删除。官方内容页对已删除条目显示“下载”，重新添加时优先复用已校验的本地包。原学科已删除时，使用同名有效学科或创建新学科，只恢复所选条目，不恢复旧上传资料或同包的其他已删除条目。

打开资料前重新读取元数据；旧窗口中的阅读按钮不能绕过删除状态。历史对话仍按原课程编号与版本读取，阅读栏提示资料已从资料库删除。刷新列表与检查内容更新同时重读归属和删除状态。

## 验收标准

- 网页下载课程后，刷新和断开服务仍能阅读保存的教材、题目及历史记录。
- 发布新版本后可检查并下载；页面显示更新后的内容。下一次更新失败或本地保存失败时，仍读取上一次成功版本。
- 历史会话不被新版本重新绑定；不同版本的相同题号不会混成同一段对话。

- 目录返回两门现有课程；下载后高数 24 题、C 语言 12 题以及教材和两份记忆文件完整，原文件字节与校验值一致。
- 发布新内容后，服务无需重启即可返回新版本；旧包仍可下载，重启后两版均可查询。
- 相同版本查询返回已是最新，历史版本返回可更新；未知本地版本明确返回未知，不自动覆盖。
- 发布失败后原目录和原下载包可用，重复发布同一内容不产生重复版本。
- 条件请求返回 304，分段下载可组合成校验通过的原包；HEAD 返回正确大小。
- 非法路径不会返回仓库其他文件，损坏包返回 503；允许和未允许的网页来源行为正确。
- 安装、发布、启动和验证命令有文档，接口可通过 OpenAPI 查看。

## 待确认事项

- 下载内容的导出备份、文件彻底删除与历史版本清理。
- 后续新增多本教材、插图等资产时的打包粒度和格式升级。
- 正式部署环境与历史版本保留期限。

## 资料分别更新

- 学习资料与题目集分别判断文件是否变化；只修改 PDF 时，题目不显示更新提示。
- 点击一份资料的“更新”，只改变该资料使用的版本和更新时间，其他资料仍可按原版本阅读。更新进度与错误只显示在对应卡片中。
- 首次下载一份资料，不把同包的其他资料标记为已下载。其他资料可以继续使用内置示例，或单独添加。
- 其他资料需要同一包内已保存的版本时，复用完整文件，不重复下载。
- 下载或保存失败时保持原条目版本；旧对话、引用和笔记仍指向原版本。并发删除、移动或更新后，重新核对资料状态再提交。
