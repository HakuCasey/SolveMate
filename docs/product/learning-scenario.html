b 明明是 double，为什么结果还是 2.0？

复习 C 语言时，我读到类型转换里的这两行代码。结果和我想的不一样，我想弄清楚小数是在哪一步丢掉的。 

int a = 5;
double b = a / 2;

对照资料问清楚

我在阅读时选中这段代码，加到侧边对话里，问为什么得到的是 2.0。看到整数除法的解释后，我又追问把 (double) 加在 a 前面，和加在整个 (a / 2) 外面有什么区别。

把想明白的地方当场记下

我把对话里有用的解释加入 C 语言笔记，整理成一句话。(double)a / 2 在除法前转换，得到 2.5。(double)(a / 2) 在整数除法之后转换，得到的还是 2.0。以后翻到这篇笔记，可以打开来源，回看当时的解释。
