03听到解释后，再问一句

SolveMate为什么结果是 2.0？对话已保存
C 语言课本.pdf · 第 42 页　double b = a / 2;
C 语言教师

这里要先看右边的 a / 2。a 和 2 都是 int，所以进行整数除法，5 除以 2 得到 2。

接下来才把这个结果赋给 b。2 转换成 double 后是 2.0，前面舍去的小数部分不会恢复。所以用 %.1f 输出时，看到的就是 2.0。

我
那我加上 (double) 就行吗？放在 a 前面，还是整个 a / 2 外面？
C 语言教师

(double)a / 2 会先把 a 转成 double，再做浮点除法，得到 2.5。

(double)(a / 2) 会先算整数除法，得到 2，再转换成 2.0。要保留这次除法的小数结果，需要在除法发生之前转换类型。
