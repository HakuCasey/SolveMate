# SolveMate 产品愿景

## 1 简介

### 1.1 愿景

知识平权——让每一位学生，都有一位因材施教的专业教师。

### 1.2 解决痛点问题

高中和大学生在自学中遇到的困惑，往往是“即时”的：教材里读不懂的一段话、一道想不通的题，当下没有人可以交流。多数人只好先记下来，等有机会再去问老师或同学。可真到了能问的时候，问题要么已经忘了，要么细节记错、变模糊了，解决效果大打折扣。

### 1.3 典型场景

#### 预习阶段

- 教材逻辑不够清晰，部分推导省略关键步骤，一旦卡住，后续预习便难以继续。
- 大学专业课推导密集，课堂难以充分展开，课后想深入理解时又缺少及时答疑。

#### 课后复习

- 做错题后难以定位错误原因，参考答案往往只有结果、缺少过程，想不透便容易搁置。
- 高中晚自习期间，遇到不会的题目难以及时求助，影响作业完成和知识消化。

#### 考试前后

- 复习时难以准确判断自身的薄弱环节，容易将时间投入已经掌握的内容。
- 大学期末复习范围广，难以判断哪些课后题对应核心考点，复习无从下手。
- 考后仍无法理解错题，课堂上又难以逐题详解，问题得不到及时解决。

## 2 核心竞争力

### 2.1 即时讨论、及时解答，让问题不过夜

- 保留问题现场：题目、教材段落、你当时的思路，都留在对话里。
- 连续追问：把“哪里不懂、为什么错、下一步怎么想”一层层讲清楚，而不是只甩一个答案。
- 手写、拍照、截图都能发，边问边改，直到真的理解透。

### 2.2 自研长时记忆系统，做一个真正懂你的“朋友”

- 懂你的风格：对“中二少年”，讲得生动形象；对“认真学究”，讲得严谨稳重、环环相扣。
- 懂你的进展：记得你上次问过什么、卡在哪里，下次接着讲，不用从头说背景。
- 懂你的不足：哪类问题问得多、哪块知识最薄弱，考前自动生成查漏补缺清单。

### 2.3 一键录入，让数字化更便捷

- 拍教材页、拍试卷、贴链接、传文档，一次录入就直接可问。
- 题干、公式、图形都能识别，不用手工敲。
- 内置大量教材和题目，既是随时可问的助手，也是随身图书馆。

### 2.4 插件化平台，知识、学科、学习阶段都按插件管理

- 学编程，装个编程插件，代码立刻跑起来；学数学，装个数学知识库，相关知识点一网打尽。
- 开放接口，官方与社区插件持续补充，支持用户自己开发。
