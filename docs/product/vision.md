# SolveMate 产品愿景

## 1. 自学和备课时，随时可以讨论

自学时，可能读不懂一段推导，或看懂了答案却不知道为什么。备课时，可能想到一种新讲法，或想试试把一个知识点出成一道题。这些问题和想法常常是在看资料的当下产生的。SolveMate 让用户可以对照原文和 AI 讨论，把问题问清楚，再接着读或继续备课。

教材、课件和题目都可以成为讨论的起点。讨论时，可以用当前页、指定页码或选段确定参考范围。上传的资料和社区下载的资料采用相同的阅读、引用和整理方式。

## 2. 产品的三个核心价值

### 对话现场完整保留

阅读时聊过的内容和当时读到的位置一起保存。过几天想接着聊，可以回到那一页或那道题，继续原来的对话。教研室里的对话也可以回到当时的工作中，接着修改讲义、试题或讲解。只要用户点过发送，这条消息就要留下，即使生成失败或中途停止。

### 重要信息及时记录

读资料或聊到一半，遇到值得留下的段落、解释或想法，可以当场记到笔记里。笔记保留出处，复习时可以回到资料原处或相关的对话。从一份资料也能找到后来围绕它形成的讨论和笔记。

资料可以直接形成笔记，也可以先经过讨论再整理成笔记。一篇笔记可以有多个来源，合并时保留各条来源。笔记本负责组织笔记。资料、对话和笔记通过稳定的编号和位置相连，资料改名或移动后，原来的关联依然成立。具体原则见[设计哲学](../architecture/overview.md#设计哲学)。

### 教研工具得心应手

教研室提供统一的 Skill 和输出模板管理入口。讲义研发、试题研发、试题精讲各有预置工具。每个工具把 Skill 和输出模板放在一起。Skill 说明任务应该怎么做，模板说明结果怎么编排。两部分可以分别查看、编辑，修改后作为一份自定义工具保存。社区工具可在同一个工作流程中选择和使用。

用户在对话里说明本次任务的范围和要求，生成初稿后可以继续提出修改意见。例如试题需要符合本次安排的题型和难度，题干要给足作答条件，答案与解析要一致。

## 3. 长期方向

- **学习记忆。** 探索根据学习进展、已有解释和用户反馈调整讲解深度与节奏，帮助用户在复习时找到反复遇到的疑问。
- **内容与能力扩展。** 在社区资料和教研工具的基础上，探索更多可共享的资料、知识资源和机器人能力，以及面向不同资料类型的阅读和引用方式。
