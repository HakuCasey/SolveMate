# SolveMate 产品愿景

## 1 简介

### 1.1 愿景

知识平权——让每一位学生，都有一位因材施教的专业教师。

SolveMate 围绕学生自己的课程资料、题目和学习记录提供阅读与讨论。学生可以选择或配置具有不同学科侧重的教师，在持续交流中获得适合自己的讲解，并积累可供后续学习使用的资料和记录。

### 1.2 解决痛点问题

高中和大学生在自学中遇到的困惑，往往是“即时”的：教材里读不懂的一段话、一道想不通的题，当下没有人可以交流。多数人只好先记下来，等有机会再去问老师或同学。可真到了能问的时候，问题要么已经忘了，要么细节记错、变模糊了，解决效果大打折扣。

### 1.3 典型场景

#### 预习阶段

- 教材逻辑不够清晰，部分推导省略关键步骤，一旦卡住，后续预习便难以继续。
- 大学专业课推导密集，课堂难以充分展开，课后想深入理解时又缺少及时答疑。

#### 课后复习

- 做错题后难以定位错误原因，参考答案往往只有结果、缺少过程，想不透便容易搁置。
- 高中晚自习期间，遇到不会的题目难以及时求助，影响作业完成和知识消化。

#### 考试前后

- 复习时难以准确判断自身的薄弱环节，容易将时间投入已经掌握的内容。
- 大学期末复习范围广，难以判断哪些课后题对应核心考点，复习无从下手。
- 考后仍无法理解错题，课堂上又难以逐题详解，问题得不到及时解决。

## 2 核心竞争力

### 2.1 即时讨论，保留问题与思考过程

- 遇到疑问，随时开聊。课本里读不懂的一段话、代码里想不通的一行，都可以当场提问，连同原文和自己的思路一起留在对话里。
- 一次没听懂，就继续问。从“这是什么意思”到“为什么能这样推”，沿着你的疑问，把概念、适用条件和关键步骤讲清楚。
- 有自己的看法，也可以直接说。和教师一起比较不同的思路、检查推理中的疑点，什么时候停下来想一想、什么时候继续，由你决定。

### 2.2 自研长时记忆系统，自演进出真正懂你的“朋友“

通过自研长时记忆系统，教师能记住共同讨论过的内容，从交流和反馈中逐渐了解你，调整自己的讲解方式。

- 记得你的进展。上次讨论了什么、哪一步还没想明白，下次可以接着聊，少一些重复交代。
- 找到适合你的讲法。你需要直观的例子，还是更完整的推导；哪些解释有帮助，哪些仍然费解，都会成为调整讲解的依据。
- 听取你的纠正。你指出的错误、补充的条件和后续讨论中的新认识，可以用来修正相关记忆，改进之后的讲解。
- 帮你安排复习。把反复问过的问题和容易混淆的知识点整理出来，帮助你决定接下来重点复习什么。

### 2.3 一键导入用户资料，围绕阅读内容提问

- 把正在使用的教材、讲义、课件、试卷、图片或网页导入进来，直接阅读，遇到不懂的地方选中内容就能提问。
- 原文中的文字、公式、图形和代码随问题一起引用，教师能看到你问的是哪里，省去来回复制、重新交代背景的麻烦。
- 原始资料和讨论保存在本地。复习时能找到当时引用的原文、教师的解释和自己的想法；还可以按需要补充官方与开源内容，整理自己的课程资料。

### 2.4 插件化平台，知识、学科、学习阶段都按插件管理

- 学什么，就添加相应的插件。按学科和学习阶段补充教材、题目和专业知识库，随着课程进展逐步扩充。
- 每位教师都可以搭配自己的 Skill 和 RAG 知识库。编程教师可以借助工具分析和运行代码，数学教师可以结合专业资料解释概念、展开推导。
- 你可以选择现有教师，也可以创建自己的教师，设置名称和角色指令，选择它使用的知识库和工具。教师的学科侧重不会限制你的选择。
- 开放接口供官方、社区和用户开发插件。官方和社区可以持续补充教师模板、知识库与学习资料，你也可以开发、分享自己的插件和内容。
