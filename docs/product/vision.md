# SolveMate 产品愿景

## 1 简介

### 1.1 愿景

知识平权——让每一位学生，都有一位因材施教的专业教师。

SolveMate 围绕学生自己的课程资料、题目和学习记录提供阅读与讨论。学生可以选择或配置具有不同学科侧重的教师，在持续交流中获得适合自己的讲解，并积累可供后续学习使用的资料和记录。

### 1.2 解决痛点问题

高中和大学生在自学中遇到的困惑，往往是“即时”的：教材里读不懂的一段话、一道想不通的题，当下没有人可以交流。多数人只好先记下来，等有机会再去问老师或同学。可真到了能问的时候，问题要么已经忘了，要么细节记错、变模糊了，解决效果大打折扣。

### 1.3 典型场景

#### 预习阶段

- 教材逻辑不够清晰，部分推导省略关键步骤，一旦卡住，后续预习便难以继续。
- 大学专业课推导密集，课堂难以充分展开，课后想深入理解时又缺少及时答疑。

#### 课后复习

- 做错题后难以定位错误原因，参考答案往往只有结果、缺少过程，想不透便容易搁置。
- 高中晚自习期间，遇到不会的题目难以及时求助，影响作业完成和知识消化。

#### 考试前后

- 复习时难以准确判断自身的薄弱环节，容易将时间投入已经掌握的内容。
- 大学期末复习范围广，难以判断哪些课后题对应核心考点，复习无从下手。
- 考后仍无法理解错题，课堂上又难以逐题详解，问题得不到及时解决。

## 2 核心竞争力

### 2.1 即时讨论，保留问题与思考过程

- 保留学习现场：将正在阅读的资料、题目、引用位置和当时的思路关联到对话中。
- 支持连续追问：围绕概念、适用条件、推导步骤和错误原因持续讨论，讲清理由和来龙去脉。
- 尊重学习节奏：学生可以提出疑问、表达自己的看法，并自行判断是否需要继续讨论。

### 2.2 长时记忆与教师的自学习、自演进

通过自研长时记忆系统积累学习过程，支持教师在持续交流中调整教学方式。

- 积累学习过程：归纳讨论中的学习进展、常见疑问、表达偏好和已有解释，使后续交流能够接续相关背景。
- 根据反馈调整教学：结合持续交流和学生反馈，调整讲解的详略、例子的选择、推导的展开程度与交流节奏。
- 持续改进专业指导：依据交流中的纠正更新相关学习记忆，结合教师的专业侧重、用户配置的资料与能力，改进解释和推导。
- 支持复习安排：结合学习记录中的问题和错误，帮助学生定位需要巩固的知识点，整理复习清单并安排后续学习。

教师以严谨、耐心和尊重学生为共同要求。因材施教体现在对学习过程的理解和教学方式的持续调整中，学生的反馈与真实学习需求是调整依据。

### 2.3 导入自己的资料，围绕阅读内容提问

- 面向教材、讲义、课件、试卷、图片和网页等资料，减少手工复制题干、公式和上下文的负担。
- 保留原始资料，根据内容类型选择合适的识别、解析和呈现方式，使学生看到的内容能够准确进入讨论。
- 将问题与引用内容关联，便于继续追问、查看历史讨论和返回相关资料。
- 支持用户整理自己的课程资料，并按需要补充官方与开源内容，使用本地保存的资料持续学习。

### 2.4 专业教师与开放扩展

- 按学科和学习需求选择或配置教师。预置教师包括全科教师、高数教师和 C 语言教师，名称和角色指令可以自定义。
- 为不同教师配置适合的 Skill 和 RAG 知识库，形成各自的专业侧重。教师的专业侧重不限制用户跨学科选择。
- 编程教师可以通过扩展能力辅助代码分析与运行；数学教师可以结合专业资料辅助概念解释和推导。
- 通过开放接口支持官方、社区及用户开发和维护扩展能力、教师模板与学习资料。
