# SolveMate 产品愿景

SolveMate 是一款面向自学的开源应用，致力于知识平权。长期目标是让 AI 能理解正在使用的资料、延续跨对话的学习过程，并通过社区扩展适应不同学科和学习阶段。

## 技术方向

### 资料驱动的知识网络

以资料为主干，把资料、对话和笔记建模为独立对象。资料可以直接形成笔记，也可以先经过对话，再把讨论中的理解整理成笔记。对象各自维护内容，由稳定 ID 和必要的位置建立关联，例如资料版本和页码，或原对话的消息 ID。这样可以沿关联找到相关记录和原始出处，改名或移动资料也能保留关联。图结构用于表达这些关系，具体存储沿用现有数据模型。见[设计哲学](../architecture/overview.md#设计哲学)。

### 自研长时记忆系统

SolveMate 计划自研跨对话的个人长时记忆。系统根据学习记录和用户反馈积累学习进度、已讨论的知识点、反复出现的疑问和有效的讲解方式。开启新对话时，可根据当前资料和问题提取相关记忆，供 AI 调整讲解深度、举例方式和推导节奏。复习时，也可结合多次讨论中的疑问和错误，帮助用户找到薄弱环节。

记忆需要能随学习过程修正。用户补充、纠正了信息，或过去卡住的问题已经解决时，后续回答应以更新后的认识和进展为依据。

### 资料理解与上下文组织

应用管理资料版本、阅读位置和本轮引用，按所选 AI 服务的能力提供页码、原文选段或文件。提问时使用与问题相关的资料，追问时延续同一段讨论。资料的引用与会话恢复由应用统一组织，服务之间的接口差异交给各自的适配器。

目前已支持 PDF、PPTX 和题目阅读。长期方向是让 AI 更准确地结合资料中的文字、公式、图表和代码理解问题，并逐步支持图片、网页等资料来源。

### 基于 Skill、知识库和插件的扩展

教研工具已经将 Skill 和输出模板作为两部分共同管理。Skill 定义任务做法，模板规定结果结构，工具可以由用户自定义，也可以通过社区发布和更新。

长期计划通过插件扩展不同学科和学习阶段的资料、专业知识和机器人能力。机器人可以结合 Skill、RAG 知识库和工具，提供有专业侧重的讲解、推导和代码实践。计划提供开放接口，让社区开发者和用户能够补充这些内容和能力。
