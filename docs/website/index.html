快速开始

源码运行需要 Git、Node.js 24、npm 11 和 Python 3.12 或以上版本。

  1. 获取源码

    在终端下载项目并安装网页依赖。

    git clone https://github.com/HakuCasey/SolveMate.git
cd SolveMate
npm ci

  2. 启动应用

    按系统安装 Python 依赖，再在仓库根目录运行： 

    npm start

    看到 SolveMate is ready 后，访问 127.0.0.1:4173。

打开应用后可直接阅读预置资料。要使用 AI，在「系统设置 → AI 配置」连接本机已安装的服务。
