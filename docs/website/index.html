带着原文提问

导入 PDF、PPTX，或打开社区资料与题目。遇到疑问时，用当前页、指定页码或选中的原文作为提问依据；回看对话时可以返回资料的位置。

快速开始

在自己的电脑上运行

准备 Git、Node.js 24、npm 11 和 Python 3.12 或以上版本。打开应用后可从预置资料开始阅读，使用 AI 前请在「系统设置 → AI 配置」连接本机已安装的服务。

完整安装说明 用户手册

获取源码

git clone https://github.com/HakuCasey/SolveMate.git
cd SolveMate
npm ci

按说明安装 Python 依赖，然后在仓库根目录执行 npm start。看到 SolveMate is ready 后，访问 127.0.0.1:4173。
